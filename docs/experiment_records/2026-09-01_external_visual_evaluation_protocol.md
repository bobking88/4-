# 真实外部视觉评测最小协议（后续阶段）

## 研究目的

在不改变当前公开标本图像训练集的前提下，评估冻结的 RSG-HRGV 模型面对独立采集图片时的性能变化。该协议服务于论文后续扩展与结题后的研究，不是对当前公开数据实验的追溯性补充。

## 不可变约束

1. 外部图像不得并入现有 8,529 张公开数据的训练、验证或模型选择过程。
2. 模型结构、已保存权重、类别映射、温度和推理阈值在外部评测前冻结；不可依据外部集结果重新选择权重或阈值。
3. 同一实体样本、同一切块、同一拍摄序列的不同视角必须使用同一个 `specimen_group_id`，评测时按该组聚类计算区间。
4. 每张图像须保留可追溯的确认依据；仅凭人工外观猜测而没有样本、专家或仪器依据的图片不进入正式外部测试。
5. 结果只能称为“独立外部视觉评测”，不能仅凭 RGB 结果称为品位预测、回收率验证或工业分选达标。

## 最小数据单元

每个 `specimen_group_id` 至少记录以下字段：

| 字段 | 含义 |
| --- | --- |
| `external_image_id` | 图像唯一编号 |
| `specimen_group_id` | 同一物理标本、颗粒批次或切块的分组编号 |
| `role_label` | 四角色标签，与当前训练任务使用同一映射 |
| `mineral_label` | 可用时记录具体矿物种类；无法确认时明确标记为空 |
| `label_evidence` | 矿物加工/地质专家确认、XRD、SEM-EDS、XRF 或既有样本台账中的一种或多种依据 |
| `label_reviewer` / `review_date` | 确认责任人与日期 |
| `source_or_mine_id` | 矿区、样本批次或标本来源编号 |
| `imaging_device` | 相机或手机型号、镜头和分辨率 |
| `lighting_setup` / `background_type` | 光源、背景与是否含比例尺等成像条件 |
| `particle_scale_or_size` | 标本尺寸、粒度区间或比例尺信息 |
| `capture_date` | 采集日期 |
| `file_sha256` | 图像完整性校验值 |

## 建议规模与采集方式

第一轮外部评测可先追求可解释性而非图像总数：每个角色至少纳入 30 个独立 `specimen_group_id`，每组可拍摄 1--3 张图像；四角色若能各达到 50 个独立组更理想。采集时应至少包含一种与 Mindat 标本图明显不同的设备、背景或照明条件，以形成真实域差异。

图片应同时覆盖完整标本、碎块或颗粒等实际可取得的形态，但必须在结果中分开记录形态。不要用大量同一标本的旋转、裁剪或连续连拍代替独立样本数。

## 标签与复核

1. 先按现有 17 类矿物--四角色映射标注；映射不明确时进入 `needs_expert`，不得强行归类。
2. 对目标矿物、含钛干扰和金属光泽困难负样本优先取得专家确认，因为它们对应当前模型的主要结构性混淆。
3. 可抽取至少 10% 的 `specimen_group_id` 由第二位复核人独立判断，并报告一致率及不一致处理过程。
4. 若图像中主体矿物不清、伴生矿物面积更大或标签纸遮挡主体，应从正式外部评测排除，同时保留排除日志。

## 冻结模型评测

对每张外部图像运行冻结的 HRGV 与 RSG-HRGV，至少报告：

- Accuracy、Macro F1 与各角色召回；
- 目标矿物召回率和漏判率；
- 含钛干扰、金属光泽干扰误入目标类比例；
- RSG 的平均路由后悔和一对一错路由选择率；
- 基于 `specimen_group_id` 的置信区间；
- 按成像设备、背景类型、形态和来源编号分层的样本数量与指标。

外部评测必须与公开固定测试集的结果并列展示。若性能下降，应报告为域差异，而不是使用外部测试集反复调参直至恢复性能。

## 暂不包含的结论

该协议不测量 Fe/V/Ti 含量、精矿品位、实际回收率、处理量、物料流、能耗或送检成本。因此，即使冻结模型在外部图片上表现良好，仍不能声称完成了工业分选验证。只有在图像与流程变量、化验结果和物料平衡能够对应时，才适合进入阶段条件化选矿决策与风险最小化研究。
