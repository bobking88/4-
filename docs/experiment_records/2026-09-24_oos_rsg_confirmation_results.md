# OOS-RSG-HRGV 多专家独立确认结果

记录时间：2026-09-24。本记录对应预先冻结的
`2026-09-22_oos_rsg_confirmation_protocol.md`，只报告协议规定的比较、终点和晋级判据。

## 1. 一句话结论

在三个独立训练的 EfficientNet-B0 专家上，专家样本外最终风险监督相对等权融合稳定降低最终 NLL，并减少含钛与金属光泽困难负样本误入目标类；但目标矿物召回平均下降 2.476 个百分点，超过预注册的 1 个百分点伤害上限，因此 OOS-RSG-HRGV 不晋级为第一篇论文主方法。

## 2. 数据与执行审计

本实验只重划原固定训练集，并按 `split_group_id` 保持重复与近重复图像组不可拆分。原验证集与原测试集均未进入本实验。

| 功能子集 | 图像数 | 作用 |
|---|---:|---|
| `expert_fit` | 3,294 | 专家参数更新 |
| `expert_stop` | 599 | 专家轮次选择 |
| `gate_seen` | 597 | 专家训练内门控监督对照 |
| `gate_unseen` | 597 | 专家样本外门控监督 |
| `gate_stop` | 597 | 门控轮次选择 |
| `final_eval` | 897 | 全部选择锁定后的最终只读评价 |

`gate_seen` 与 `gate_unseen` 的 17 个矿种-角色分层计数逐项相同。除 `gate_seen` 按设计属于 `expert_fit` 外，其余功能子集之间的图像组交叉为 0。完整数据集有 35 张钛磁铁矿图像，本协议只使用原训练集中的 17 张，其中 `final_eval` 仅 2 张，不能据此给出稳定的钛磁铁矿单类结论。

三个专家均从 ImageNet 权重独立初始化，种子为 20260924、20260925 和 20260926。专家与门控检查点在读取 `final_eval` 前完成选择和哈希锁定；seen/unseen 配对门控共享同一专家、初始化、批次顺序和超参数，仅门控监督来源不同。

## 4. 最终评价结果

效应统一定义为 `unseen - baseline`。NLL、误入率和目标漏识风险以负值为有利方向；Accuracy、Macro F1 和目标召回以正值为有利方向。95% 区间由 10,000 次两阶段成对 Bootstrap 得到，先重采样专家种子，再在每个矿种-角色层内按 `split_group_id` 重采样图像组。

### 4.1 样本外监督相对专家训练内监督

| 指标 | 平均差 | 95% 区间 | 三专家方向 |
|---|---:|---:|---:|
| 最终 NLL / nat | -0.035656 | [-0.050196, -0.023217] | 3/3 有利 |
| Accuracy | -0.334 个百分点 | [-1.153, 0.447] | 0/3 提高，1/3 持平 |
| Macro F1 | -0.497 个百分点 | [-1.523, 0.484] | 0/3 提高 |
| 目标召回 | -4.762 个百分点 | [-7.238, -2.286] | 0/3 提高 |
| 含钛误入目标 | -1.559 个百分点 | [-3.119, -0.390] | 3/3 有利 |
| 金属光泽误入目标 | -2.133 个百分点 | [-4.533, 0.000] | 2/3 有利，1/3 持平 |

样本外监督在三位专家上均降低了最终 NLL，并降低两类困难负样本误入；同时目标召回在三位专家上均下降。这一结果说明门控训练目标确实改变了风险分配，而不是无条件改善所有分类指标。

### 4.2 样本外监督相对等权融合

| 指标 | 平均差 | 95% 区间 | 预注册判断 |
|---|---:|---:|---|
| 最终 NLL / nat | -0.014040 | [-0.019431, -0.008724] | 通过 |
| Accuracy | +0.037 个百分点 | [-0.668, 0.743] | 描述性 |
| Macro F1 | -0.047 个百分点 | [-0.786, 0.749] | 通过 0.5 点伤害上限 |
| 目标召回 | -2.476 个百分点 | [-4.381, -0.571] | **未通过 1 点伤害上限** |
| 含钛误入目标 | -1.170 个百分点 | [-2.242, -0.292] | 通过 |
| 金属光泽误入目标 | -1.600 个百分点 | [-3.733, 0.000] | 通过 |

NLL 在三个专家上分别改善 -0.014569、-0.015754 和 -0.011798 nat，方向完全一致；但目标召回下降同样方向一致。因此，根据“所有主要终点与伤害护栏同时通过”的预注册规则，`promote_to_main_method=false`。

### 4.3 相对原联合门控

样本外门控相对原联合门控的最终 NLL 平均改善 -0.062606 nat，95% 区间为 [-0.076690, -0.048958]；含钛和金属光泽误入分别下降 2.339 和 2.667 个百分点。目标召回同时下降 5.333 个百分点，95% 区间为 [-7.619, -3.048]。该比较再次显示当前路由器沿着“降低校准风险与困难负样本误入、牺牲目标召回”的方向移动。

## 5. 晋级判定

| 预注册条件 | 结果 |
|---|---|
| `unseen - equal` NLL 均值及 95% 区间上界均小于 0 | 通过 |
| 至少 2/3 专家 NLL 方向有利 | 通过，3/3 |
| Macro F1 下降不超过 0.5 个百分点 | 通过 |
| 目标召回下降不超过 1 个百分点 | **未通过** |
| 含钛误入目标上升不超过 1 个百分点 | 通过 |
| 金属光泽误入目标上升不超过 1 个百分点 | 通过 |

结论：OOS-RSG-HRGV 保留为得到独立支持的风险路由机制，但不替代现有 RSG-HRGV 主方法。它证明了样本外监督能够改善正确概率风险与困难负样本控制，却也揭示了一个需要新网络约束解决的稳定失效模式。

## 6. 后续理论假设

下一步候选方法为目标召回约束的样本外风险路由器，暂记为 TC-OOS-RSG。其目标不是继续无约束压低 NLL，而是在等权融合可行回退的条件下求解

\[
\min_{\phi} R_{\mathrm{NLL}}(\phi)
\quad\text{s.t.}\quad
R_{T,\mathrm{miss}}(\phi)
\le R_{T,\mathrm{miss}}(g\equiv 1/2)+\epsilon.
\]

可使用拉格朗日形式

\[
\mathcal L(\phi,\lambda)=R_{\mathrm{NLL}}(\phi)
+\lambda\left[R_{T,\mathrm{miss}}(\phi)-\tau\right],
\qquad \lambda\ge 0,
\]

并在与门控拟合、门控停止和最终评价均隔离的约束集上估计目标风险。该方法及其可微代理、有限样本安全裕量和新的独立评价协议尚未完成，因此不能写成已验证贡献。当前 `final_eval` 已经被读取，后续方法不能再使用同一集合进行确认性调参或最终确认。

## 7. 证据边界

上述结论只适用于公开矿物标本图像和既定四角色标签。它不证明真实矿石颗粒、工业皮带、品位、回收率、钒钛元素含量或跨网站外部泛化性能。
