# 固定专家门控试验的最终输出重放

## 协议与证据

执行 `scripts/audit_final_output_gate_pilot.py`，读取已有单个 HRGV 专家检查点和先前六个已选定门控检查点；冻结专家及验证器，只读取 1,284 张验证图像。本轮不训练、不选新配置、不读取测试图像。三种子只对应门控初始化，不能作为三个独立专家实验。

指标计算在同一组实际专家、同一对验证器上进行；验证前 NLL 与历史试验逐配置误差小于 2e-5，专家参数及缓冲区重放前后精确不变。分类指标还通过四类完美预测的已知答案检查。

结果及检查点哈希：`outputs/theory/final_output_gate_pilot/summary.json`。七份逐图 CSV 保存图像 ID、分组 ID、门控、有效门控与各损失对门控 logit 的偏导。CSV 不包含图像本身。

后悔 BCE 相对等权最终 NLL 差为 −0.001151 nat，Macro F1 差为 −0.0567 个百分点。验证前 NLL 门控的 Macro F1 较高，而 NLL 更差，提醒我们两种评价目标不等价。不能据表挑选“最优方法”再报告为独立确认。

## 梯度诊断

在三个后悔 BCE 门控中，后悔辅助项与最终 NLL 的单样本门控 logit 偏导反向计数分别为 403、423、350；验证前与最终 NLL 的偏导反向均为 14/1284。阈值为两偏导乘积小于 −1e-12。前者并不全由验证器导致，还包含标签相关软目标与融合风险之间的差异。

这里比较的是固定专家条件下的标量偏导，不是整个门控网络参数梯度的夹角，更不是共享主干的梯度冲突率。后悔辅助项尚未乘训练损失系数或批量归一化系数；冲突计数不能说明它在总梯度中占主导，也不能证明它导致现有性能结果。等权配置的偏导仅作该位置的假想局部诊断，不表示等权模型进行了梯度更新。

## 对网络创新的影响

现有证据支持研究“最终输出风险与辅助门控监督的相容性”，而非直接宣称已有门控显著提高识别性能。需要的首个新增对照是固定专家、固定验证器下直接优化最终 NLL，而不是再次优化验证前 NLL。该对照属于必要实验，不是新方法。正式联合模型早已包含最终输出损失，因此不能将这项对照描述成修复原模型遗漏。

若进一步设计约束，必须与直接最终 NLL、原辅助项及通用梯度处理基线比较；并检查方法是否只是现有多任务梯度投影或等价重参数化。不能只因训练梯度更一致就推断验证集或测试集性能改善。

本轮没有修订正式报告的性能结论。后续报告可采用上述机制分析，但应先完善独立训练对照，并保持探索性验证集结论与独立确认的区别。
