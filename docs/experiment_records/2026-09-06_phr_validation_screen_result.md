## 3. 预注册晋级规则复核

完整 PHR 相对 RSG 参考的 Macro F1 变化为 `-0.0070`，Accuracy 变化为 `-0.0093`，目标类召回变化为 `-0.0480`。Ti 与金属光泽误入目标率分别增加 `0.0041` 与 `0.0113`；两条成对遗憾分别降低约 `56.7%` 和 `63.1%`。

因此三条预注册规则均不成立：

1. Macro F1 未提高 0.005，故不满足总体性能规则；
2. 虽然两条成对遗憾均降低超过 10%，但目标类召回下降远超过 0.003，故不满足局部风险规则；
3. Accuracy 变化超过 0.003，且目标类召回没有提高，故不满足风险取舍规则。

据此，不启动 RSG 与完整 PHR 的正式三随机种子测试，也不在论文或技术报告中写作 PHR 的性能提升。

## 4. 对理论命题的支持与边界

本筛选没有否定 PHR 的解析性质：成对边际遗憾恒等式、软目标的损失界、两边约束的最小范数投影和符号保持条件已由 `scripts/verify_phr_theory.py` 在固定种子双精度合成样本上复核。它同时提供了一个脉石 logit 不变而脉石 Softmax 概率改变的反例。

真实验证结果进一步提供了一个重要边界证据：**局部成对遗憾显著降低，并不保证四分类 Macro F1、目标类召回或关键误入率改善。** 这与 PHR 理论文档中的扰动界和反例一致：受约束的两条 logit 边界会经 Softmax 耦合影响全部类别，局部优化与全局业务风险不是同一目标。

这是一项机制性负结果，而不是所提出网络具有普遍优势的证据。报告可以保留其公式、网络结构与严格筛选设计，用来说明方法边界和研究规范；但当前第一篇论文的实证主线仍应采用已完成、已验证的 RSG-HRGV 分层角色一致性结果。

## 5. 后续研究决定

1. 不继续围绕本次 PHR 在同一冻结验证集上增加变体或调超参数，避免验证集过拟合。
2. 将 PHR 保留为“成对约束局部优化与全局风险脱钩”的负结果附录，而非主方法性能贡献。
3. 下一项网络创新应先在独立的数据划分或来源留出场景定义明确的全局目标，再进行预注册比较；候选方向是以目标漏检与两类误入为显式约束的整体风险优化，而不是继续强制单对边际。
4. 完成 RSG-HRGV 主线的来源外验证、磁铁矿代理消融与目标代理指标汇总，并以这些已完成证据扩充技术报告和论文实验章节。
