# 固定专家后的路由机制审计

## 问题

不同模型的专家后验可能不同。因此模型 A 与 B 的路由后悔差，不能直接解释为固定专家条件下门控的因果效应。
对模型 j，精确恒等式为 L_fused,j = L_oracle,j + r_j。
所以 ΔL_fused = ΔL_oracle + Δr；专家质量与路由变化须分别报告。
所有对数损失单位为 nat，不是概率或百分点。
