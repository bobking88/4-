# HRGV-Net 三随机种子实验记录

## 1. 实验目的

本轮实验验证面向钒钛矿相关矿物角色识别的层级风险门控验证网络（HRGV-Net）。模型以 EfficientNet-B0 为共享视觉骨干，同时学习四分类角色后验、17 类矿物种类后验、矿物种类到角色的固定映射、可靠性门控、两个目标类难负样本验证器及角色感知对比表征。

本轮只评价公开矿物标本图像上的视觉代理任务，不评价工业皮带分选、精矿品位、回收率或钒钛含量。

## 2. 固定实验条件

- 数据清单：`数据集/dataset_final_v1/dataset_split_manifest_v1_0.csv`
- 图像根目录：`数据集/mindat_manual_positive_v1`
- 固定种子：`20260727`、`20260728`、`20260729`
- 骨干网络：ImageNet 预训练 EfficientNet-B0
- 检查点选择：验证集 Macro F1 最大值
- 测试集：固定 1,284 张，不参与超参数选择
- 重复控制：沿用既有 SHA-256、Mindat photo ID、dHash 与 `split_group_id` 分组策略
- 推断统计：以种子为第一层、`split_group_id` 为第二层的成对分组自助法；组内图像不拆散

正式实验由以下命令矩阵生成：

```powershell
python scripts/run_hrgv_experiments.py `
  --manifest "数据集/dataset_final_v1/dataset_split_manifest_v1_0.csv" `
  --dataset-root "数据集/mindat_manual_positive_v1" `
  --configuration residual_coupled `
  --configuration equal_fusion `
  --configuration no_contrast `
  --execute
```

## 3. 模型配置

| 配置 | 作用 |
|---|---|
| `residual_complete` | 耦合梯度、学习门控、残差双验证器、角色感知对比约束；当前 HRGV 主模型 |
| `equal_fusion` | 将学习门控固定为 0.5，检验自适应门控贡献 |
| `no_contrast` | 对比损失权重设为 0，检验难负样本对比约束贡献 |
| `decoupled_residual` | 验证器特征停止梯度，检验梯度隔离的召回与风险取舍 |
| `gate_only` | 禁用最终双验证器及其损失，检验风险验证贡献 |
| `complete` | 原始乘法验证器试验，保留为失败设计对照 |

## 4. 三随机种子结果

表中为均值 ± 样本标准差。

| 配置 | Accuracy | Macro F1 | 目标召回 | 含钛干扰误入目标 | 金属光泽干扰误入目标 |
|---|---:|---:|---:|---:|---:|
| 耦合残差 HRGV | 76.48% ± 0.23% | 74.59% ± 0.34% | 72.38% ± 3.22% | 9.16% ± 1.13% | 11.55% ± 1.18% |
| 固定 0.5 等权融合 | 75.91% ± 0.29% | 74.01% ± 0.33% | 73.04% ± 2.99% | 9.78% ± 1.47% | 12.31% ± 2.37% |
| 去掉对比约束 | 75.39% ± 0.86% | 73.51% ± 0.56% | 71.05% ± 2.65% | 9.78% ± 2.74% | 10.98% ± 2.15% |
| 验证器梯度隔离 | 74.71% ± 1.56% | 72.99% ± 2.15% | 75.03% ± 4.30% | 10.05% ± 0.62% | 13.64% ± 2.05% |
| 仅门控、不做最终验证 | 76.74% ± 0.65% | 74.91% ± 0.41% | 74.37% ± 0.83% | 9.78% ± 1.47% | 11.74% ± 0.87% |
| 原始乘法验证器 | 75.91% ± 0.83% | 74.25% ± 1.02% | 71.05% ± 1.80% | 9.91% ± 1.05% | 12.12% ± 0.87% |

## 5. 主要消融结论

### 5.1 学习门控与等权融合

相对固定 0.5 融合，学习门控平均提高 Accuracy 0.57 个百分点、Macro F1 0.58 个百分点，并将含钛与金属光泽误入率分别降低 0.61 和 0.76 个百分点，但目标召回下降 0.66 个百分点。Macro F1 差值的 95% 分组自助区间为 -0.72 至 1.99 个百分点，跨越 0。

因此只能表述为：学习门控在本数据集上呈现小幅风险平衡优势，但尚无充分证据证明其显著优于简单等权融合。

### 5.2 角色感知对比约束

去掉对比约束后，Accuracy 平均下降 1.09 个百分点，Macro F1 平均下降 1.08 个百分点，目标召回下降 1.33 个百分点。以“无对比模型减完整模型”计，Accuracy 的 95% 区间为 -2.15 至 -0.08 个百分点，Macro F1 的 95% 区间为 -2.06 至 -0.12 个百分点，均未跨越 0。

因此，角色感知对比约束对总体分类性能具有可重复的正贡献；但它对两类误入率的影响并不同时有利，不能写成普遍降低所有难负样本误收。

### 5.3 双验证器及风险取舍

相对“仅门控”模型，耦合残差双验证器将含钛误入率由 9.78% 降至 9.16%，金属光泽误入率由 11.74% 降至 11.55%，但目标召回由 74.37% 降至 72.38%，Macro F1 也低 0.33 个百分点。相关区间均跨越 0。

因此，双验证器当前表现为风险控制模块，而非无代价的准确率增强模块。技术报告应同时报告漏选与误入，不能只展示误入率下降。

### 5.4 原始乘法验证与中性区残差验证

原始设计直接使用两个验证器目标概率相乘，导致即使验证器支持目标，也会系统性缩小目标证据。中性区残差验证规定当验证器输出高于阈值时保持恒等，只在明显反对目标时衰减目标证据。

相对原始乘法设计，中性区残差版本平均提高 Accuracy 0.57 个百分点、Macro F1 0.34 个百分点、目标召回 1.33 个百分点，并降低两类误入率。差异区间仍跨越 0，因此该结果支持结构修正的方向，但不构成显著优越性证明。

### 5.5 验证器梯度隔离

停止验证器损失向共享骨干传播后，目标召回平均提高 2.66 个百分点，但 Accuracy 下降 1.77 个百分点，Macro F1 下降 1.60 个百分点，金属光泽误入率上升 2.08 个百分点，且种子波动显著增加。

因此，完全梯度隔离只能保留为召回优先变体，不作为当前主模型。实验说明验证器辅助任务与共享表征之间存在真实取舍，但“完全耦合”与“完全隔离”都不是无条件最优。

## 6. 与既有层级模型的成对比较

耦合残差 HRGV 相比既有层级 EfficientNet-B0：

- Accuracy 平均提高 1.06 个百分点，95% 区间为 -1.30 至 3.92 个百分点；
- Macro F1 平均提高 1.18 个百分点，95% 区间为 -1.12 至 3.93 个百分点；
- 含钛误入率降低 1.77 个百分点；
- 金属光泽误入率降低 2.84 个百分点；
- 目标召回下降 5.18 个百分点，95% 区间为 -10.23 至 0.27 个百分点。

以上多数区间跨越 0，结论应写成“观察到风险取舍趋势”，不写成统计显著的全面提升。普通加权交叉熵旧实验未保存逐图预测文件，暂时只能做三种子汇总比较，不能伪造成对检验。

## 7. 验证器可分性

正式 HRGV 配置的两个验证器在各自“目标类 vs 指定难负样本”子集上的 ROC-AUC 约为 0.91 至 0.92，说明它们确实学到了可分信息。但较高验证器 AUC 并不自动保证最终四分类性能提高，因为后验修正仍会改变召回与误入之间的阈值取舍。

## 8. 当前结论与报告表述

1. HRGV-Net 的创新应定位为“层级双专家、可靠性融合、难负样本风险验证及其可审计取舍”，不能写成全面显著优于所有基线。
2. 对比约束获得了最清晰的正向消融证据，可作为当前方法贡献之一。
3. 门控优于等权融合的证据较弱，应使用“呈现小幅优势”而非“显著提升”。
4. 双验证器降低部分误入但牺牲目标召回，必须以风险曲线或多指标表呈现。
5. 梯度隔离实验是有价值的负结果，证明辅助任务耦合存在取舍，但不应作为主模型。
6. 所有结论限于公开标本图像闭集识别，不等同于工业现场分选性能。
