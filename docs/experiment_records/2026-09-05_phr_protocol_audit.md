## 1. 审计结论

此前 `outputs/training/phr_hrgv_screen/` 下的筛选队列不能用于方法结论、论文图表或正式多种子比较。该目录仅保留为可追溯的中断记录，不覆盖、不删除，也不重命名为正式结果。

原因如下：

1. `rsg_reference` 曾错误附带关闭全局 RSG 遗憾学习的标志；其他配置也没有一致启用注册的 RSG 基线权重，因此并非同一 RSG 对照。
2. 固定半门消融实际控制的是全局门而非两个成对门，且单边消融未将未启用边从统计诊断中排除。
3. 筛选训练曾可输出测试集指标，违反“只用验证集选配置”的预注册约束。
4. 原分析将宏召回误称为 Macro F1，且存在把合并种子观测当作种子平均估计量的风险；不应据此报告不确定性区间。
5. 旧注册文件未固定完整代码哈希、没有逐运行日志/状态机，也无法从验证证据重新判断晋级条件。

已确认旧目录中的 `rsg_reference/seed20260728` 仅含环境与检查点等中断产物，未产生完整的可用筛选指标。2026-09-05 已终止该错误队列的已确认进程树；本记录不将“终止”解释为任何实验结果。

## 2. v2 不变协议

- 冻结清单：`数据集/dataset_final_v1/dataset_split_manifest_v1_0.csv`。
- 模型主干：EfficientNet-B0；RSG 对照与 PHR 使用相同的图像、划分、优化器和全局 RSG 参数。
- 所有筛选命令含 `--validation-only`，只输出 `val_metrics.json` 和 `val_predictions.csv`；不读取或保存测试集评估结果。
- 筛选配置固定为 RSG 对照、完整 PHR、固定半门、硬目标、无权重、特征耦合、Ti 单边和金属光泽单边，共八个配置，一个固定种子 `20260728`。
- 单边消融的未启用边保持 RSG 基准对数几率，并在成对统计中标记为不参与，不能与活跃边遗憾并列比较。
- 每个运行写入 `train.log`、`run_status.json`、环境、最佳验证指标和预测文件。运行失败或中断时保留目录并拒绝覆盖。
- 注册文件记录清单哈希、Python/PyTorch/CUDA 环境、Git 提交和 `scripts/*.py` 的 SHA-256。代码或清单改变时，必须使用新的输出目录。

## 3. 验证集晋级规则（预先固定）

完整 PHR 只有满足至少一项才进入正式的三个随机种子比较：

1. 验证集 Macro F1 相对 RSG 增加至少 0.005，且 Ti、金属光泽两类误入率并非同时恶化；
2. 两条活跃边平均遗憾均至少降低 10%，且目标类召回下降不超过 0.003；
3. Accuracy 绝对变化不超过 0.003，目标召回严格提高，并且至少一项关键误入率严格降低。

`scripts/generate_phr_screen_decision.py` 读取八个完整的验证集输出，检查非 smoke、验证集限定与哈希后，生成 `screen_decision.json`。它将指标、源代码哈希和全部验证产物哈希封装为证据。`scripts/run_phr_hrgv_experiments.py --mode formal` 会重新计算这些哈希和三条规则；任一证据改变、规则不匹配或没有晋级都会拒绝启动正式训练。

## 4. v2 筛选结论与禁止表述

网络契约、单元测试、数值性质检查和验证集专用运行链路均已完成。
`outputs/theory/phr_properties_v2.json` 是固定种子双精度的合成数值核验，证明实现满足指定恒等式/约束，并包含一个四分类 NLL 可能上升的反例。

v2 筛选的自动决定文件为 `outputs/training/phr_hrgv_screen_v2/screen_decision.json`。它的 `criterion_ids=[]`、`promote_to_formal=false`：完整 PHR 虽将两条成对遗憾由 `0.4187/0.6374` 降至 `0.1813/0.2350`，但 Macro F1 由 `0.7485` 降至 `0.7414`，目标类召回由 `0.7360` 降至 `0.6880`，且两项关键误入率均上升。按预注册规则，不启动正式多种子测试。

禁止写：

- “PHR 提升了 Macro F1”；
- “PHR 显著优于 RSG”；
- “PHR 不影响脉石类别”；
- “两条困难负样本边的改进必然改善四分类性能”。

允许写：PHR 的成对遗憾恒等式、最小范数修正及扰动上界已给出解析推导，并在合成数值上复核；该候选在本轮冻结验证集筛选中未获得整体性能或目标代理风险改善，作为局部成对优化不保证全局四分类收益的机制性负结果保留。
