# 角色感知困难负样本学习：三随机种子实验记录

## 方法定位

本方法服务于公开矿物标本图像上的四分类视觉代理任务，而非品位预测或工业分选验证。其目标是针对错误分析中最关键的两类“非目标误入目标”方向建立可解释的风险取舍：

- 目标矿物 ↔ 含钛干扰矿物；
- 目标矿物 ↔ 金属光泽干扰矿物。

模型以 EfficientNet-B0 为共享特征主干，包含四分类主头、目标代理/非目标代理二分类辅助头与 128 维投影头。训练目标为：

`L = L_four_class + 0.25 * L_binary + 0.10 * L_role_contrast`

其中，`L_role_contrast` 只在上述两类关系中拉开目标矿物与困难干扰的特征表示；脉石/废石以及其他类别关系仍由四分类主任务学习。

## 受控实验协议

- 固定数据版本：`dataset_final_v1`；
- 固定划分：训练 5,961 张、验证 1,284 张、测试 1,284 张；
- 随机种子：20260727、20260728、20260729；
- 主干初始化：ImageNet 预训练 EfficientNet-B0；
- 优化器：AdamW；早停依据：验证集 Macro F1；
- 对照：普通 EfficientNet-B0 类别加权交叉熵与类别加权 Focal Loss。

## 结论边界

该方法的总体 Macro F1 仅比普通 EfficientNet-B0 高 0.15 个百分点，小于种子间标准差，因此不应宣称总体识别性能显著提高。

但它将含钛干扰误入目标的比例降低 2.10 个百分点、金属光泽干扰误入目标的比例降低 1.89 个百分点，同时目标漏选率增加 3.59 个百分点。结果符合“更保守地判定目标”这一机制预期。因此可将其作为论文的应用方法原型：通过角色关系约束改变关键风险错误的分布，并以目标漏选与干扰误入之间的权衡作为评价重点。

后续工作不宜继续堆叠网络，而应由选矿专家定义可接受的漏选阈值与误入阈值，在真实矿石或来源外测试集上调节辅助损失权重并寻找运行点。

## 理论感知分层扩展

在角色感知困难负样本模型基础上，进一步使用固定的 17 类矿物种类—四类选矿角色映射进行理论化分层建模。共享 EfficientNet-B0 视觉特征并列连接角色头、种类头、目标代理二分类头和投影头；种类头到角色层的联系是概率聚合，而不是输出头串联：

`p_tilde_r = A p_s`

一致性项严格采用：

`L_cons = KL(p_r || p_tilde_r)`

完整损失为：

`L = L_role + 0.50 L_species + 0.10 L_cons + 0.25 L_binary + 0.10 L_hard`

组件消融的可复现汇总为 `outputs/business_metrics/hierarchical_component_ablation/hierarchical_component_ablation_summary.json`。完整模型、去除困难负样本约束、去除层级一致性约束三组的平均 Macro F1 分别为 73.41%、73.63%、73.40%；均值差与三个随机种子的样本标准差同量级，因此只记录风险指标方向，不作统计显著或稳定领先声明。

## 角色可识别性受控逻辑验证

证据文件：`outputs/theory_validation/role_identifiability/role_identifiability_summary.json`。

- 固定随机种子：20260801；
- 候选集规模：2、3、4；
- 角色一致候选集：48 个，种类唯一可识别率 0.00%，角色唯一可识别率 100.00%；
- 角色冲突候选集：51 个，种类唯一可识别率 0.00%，角色唯一可识别率 0.00%。

该实验只验证“候选种类全部映射到同一角色时，角色仍可唯一确定”的逻辑条件。它不使用模型预测，不推断原图真实多标签，也不构成外部或工业验证。

## 固定划分选择性识别

证据文件：`outputs/theory_validation/selective_recognition/selective_recognition_summary.json`；图：`outputs/paper_figures_v1/fig9_selective_recognition.png`。

三个完整分层模型均使用未改变的固定测试划分。阈值 0.00 时，平均覆盖率为 100.00%，保留样本错误率为 24.58%；阈值 0.90 时，平均覆盖率为 60.88%，保留样本错误率为 11.71%；阈值 0.95 时，平均覆盖率为 51.61%，保留样本错误率为 9.92%。较低覆盖率表示更多样本被延后检查，体现的是固定公开图像测试划分上的覆盖率—风险取舍。

## 新增结论边界

当前新增证据只支持三项内容：角色层理论形式化、受控逻辑条件验证、固定测试划分上的选择性识别评价。阶段条件化决策、真实动作与检查成本矩阵、XRF 多模态确认、来源留出测试、独立外部验证、真实矿石成像和统计显著性检验均为未来工作。不得把 `defer` 解释为已验证的工业处置或 XRF 成本最优策略，也不得把类别代理指标解释为品位、回收率或生产线分选性能。
