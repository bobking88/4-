## 根因证据与设计决策

上一轮[独立只读复查](2026-10-16_msb_execution_contract_repair_independent_review.md)已经改变下一步行动：四项 P2 需先修复，不能进入真实运行。本轮基于当前源码局部静态路径继续细化，不执行反例。

| 问题 | 拟议设计 | 计划覆盖 |
|---|---|---|
| 最后成功写入跨期 | 元数据先整理；唯一成功发布带写前/后检查；异常撤销且失败写入另计 | Task1，最后状态写入/撤销写失败/预算等号反例 |
| 启动后异常丢进程 | 父端持有 WorkerLaunchOwnership；整体 BaseException 保留对象与原/次级错误；未知创建明确不确定 | Task2，日志退出、中断、恢复失败、无对象四类路径 |
| 退出早于父读完终结消息 | 观察退出后再有界排空；进程退出与读取消息分离 | Task3，读暂空后 DONE+exit 交错及坏帧/超界 |
| 续租与 DONE 竞争 | CLOSE_REQUEST/CLOSE_GRANT/DONE；唯一在途续租；同锁序列化 ACK 和终结写入 | Task3，两个合法交错和重放/缺 ACK 等拒绝路径 |

不采用“增加等待”“接受任意较旧 DONE”或更换整个 IPC 框架。新增终结消息属于执行协议，不增加网络、拟合、前向或科学任务。

## 作者自审

这是作者文档自审，不是新独立复查，也没有派发代理。

- 覆盖：T1--T4 分别映射到 Tasks1/2/3；Task4 处理九模块合成、43项身份和历史保护。
- 接口：显式 granted_tick_ms 决定初始续租原点，不能从受总期限截短的 lease 倒推；父端记 last_acked 与唯一 outstanding，而非只保留 acked bool。
- 并发：子主线程不抢读、不持锁等事件；状态/ACK/REQUEST/DONE 同锁；CLOSE_REQUEST 后父不再发新 RENEW，但必须确认已在途 ACK。
- 失败：不知道是否创建不能报 attempts=0/cleanup_confirmed=True；最终文件撤销失败不能声称已持久化；均不进入下一 job。
- 证据：旧 121 项是作者历史合成记录，不代表本规格已被验证；原生时序、断电/硬杀及不可中断 I/O 不作完整保证。
- 范围：未来只改两项执行源码；未改科学公式/损失/矩阵/晋级门，不把状态机设计当论文理论创新。

静态链接、未完成占位和文档空白检查在提交前核对；这些不是测试或合成运行。新文档中的未来命令未执行。
