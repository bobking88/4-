# 来源元数据可行性审计（2026-09-01）

## 目的

评估现有公开标本图像元数据能否支持比摄影者整体留出更严格的矿区、收藏机构或网站来源整体留出测试。审计只读取最终数据集清单与主清单，不重新训练模型、不修改数据划分。

## 审计对象

- 主清单：`数据集/dataset_audit/dataset_master_manifest.csv`；
- 最终实验清单：`数据集/dataset_final_v1/dataset_split_manifest_v1_0.csv`；
- 最终图像数：8,529；
- 检查字段：`locality`、`photographer_or_credit`、`source_site`、`source_type`、`four_class_label`。

## 结果

| 项目 | 结果 | 对整体留出测试的含义 |
| --- | ---: | --- |
| 有效 `locality` 图像 | 4,875 / 8,529（57.16%） | 仍有 42.84% 图像没有可用矿区字段，不能代表完整数据集 |
| 有效矿区文本组 | 2,388 | 文本粒度不统一，部分条目属于地区、矿区或采集点混用 |
| 每组至少 10 张的矿区 | 59 | 可用于小规模探索，但不足以形成统一、稳定的完整测试协议 |
| 每组至少 20 张且覆盖至少 3 个角色的矿区 | 0 | 不能形成类别均衡的多角色矿区留出集 |
| `photographer_or_credit` 非空图像 | 5,639 / 8,529（66.12%） | 已用于 3,947/846/846 摄影者整体留出协议 |
| 来源站点字段 | `mindat.org` 4,916；`Mindat` 3,613 | 两个值是同一站点的拼写差异，不能构成网站来源外测试 |
| 来源类型字段 | `online_mineral_gallery` 4,916；`manual_download` 3,613 | 反映获取方式，不是独立成像域或独立数据来源 |

四角色在拥有有效矿区字段的子集中的数量分别为：目标矿物 1,445、含钛干扰 1,084、脉石/废石 1,903、金属光泽困难负样本 443。尽管每类均有一定覆盖，但高频矿区通常只含一个角色。例如，Cerro Huañaquina（68 张）只出现目标矿物，Siglo Veinte Mine（52 张）和 Dara-e-Pech pegmatite field（50 张）只出现脉石/废石。按单一矿区留出会把矿区属性与类别标签绑定，导致结果无法区分“模型是否识别了矿物角色”和“测试矿区是否只包含一种角色”。

## 结论

1. 不建立“矿区整体留出”主实验或附加实验。现有字段的覆盖率、标准化程度和角色共现结构均不足以支持这一结论。
2. 摄影者整体留出保留为现阶段来源变化的正式确认，因为其字段覆盖更高，且已同时约束摄影者与 `split_group_id` 不交叉。
3. 网站来源整体留出不可开展，因全部图像都来自 Mindat 生态，`source_type` 仅表示获取方式。
4. 后续真实外部测试应使用独立采集的颗粒或标本图片，并最少记录：样本或矿区编号、矿物/岩性确认依据、拍摄设备、光照、背景、粒度/尺度和采集日期。外部数据只用于评估，不与当前公开图像混合训练。

## 与论文和技术报告的对应

论文与技术报告可陈述“摄影者整体留出用于检验公开标本图片中摄影风格变化下的机制稳定性”，但不得将其写成矿区外、网站外、真实工业外部验证或 OOD 测试。矿区整体留出和真实颗粒外部测试应在取得标准化元数据和专家确认标签后作为下一阶段研究。

## 复核方法

审计以最终清单的 `image_id` 筛选主清单；空 `locality` 和字面值为 `Description` 的条目不计为有效矿区。对有效矿区按文本完全匹配分组，统计每组图像数和四角色数。该规则是可复核的数据质量判断，不对自由文本矿区名称进行地理编码或人工合并，因此不引入额外不可追溯的规范化假设。
