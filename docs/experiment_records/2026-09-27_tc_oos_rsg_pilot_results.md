# TC-OOS-RSG Fold 0 先导实验记录

## Material Passport

- 实验编号：`TC-OOS-RSG-PILOT-F0-20260929`
- 实验类型：锁定协议下的单外层折方法有效性先导实验
- 状态：`ANALYZED / METHOD GATE NOT PASSED`
- 数据范围：公开矿物标本图像开发池，Fold 0 外层评估集 1,696 张
- 代码版本：`codex/theory-aware-report`，Task 7 后提交 `1f8f44f`
- 协议：`tc_oos_rsg_v1`
- 设备：NVIDIA GeForce RTX 5050 Laptop GPU，7.96 GB
- 结论边界：仅支持公开标本图像上的模型与理论验证，不支持工业分选、品位、回收率或硬召回保证。

## 1. 目的

本实验不是用于选择一个好看的外层结果，而是检验 TC-OOS-RSG 是否具备进入正式三折实验的最低方法有效性：

1. 分层专家、OOS 候选门控和目标约束投影可以按锁定协议完整运行；
2. 外层评估张量只能在门控、投影器及 `epsilon_target` 全部锁定后读取；
3. 路由不是常数，目标约束在需要时能够实际截断无约束路由；
4. 单纯回退 `q0`、无约束路由与最终 TC 路由在概率层面必须可区分；
5. 单纯形、逐图目标后验下界、精确凸组合分解和凸 NLL 上界必须零违规。

## 2. 数据隔离与锁定

```text

```

因此，外层图像未参与专家、门控、投影器或风险预算选择。

## 5. 数学不变量核验

所选风险预算为 `epsilon_target = 0.08`。在 1,696 张外层图像上：

| 不变量 | 违规数 |
|---|---:|
| 单纯形有效性 | 0 |
| 逐图目标后验下界 | 0 |
| 精确凸组合分解 | 0 |
| 凸 NLL 上界 | 0 |
| 非有限值或负概率 | 0 |

- 最大逐图目标后验损失：0.069745，小于 0.08；
- 最大分解残差：`8.40e-08`，小于 `1e-06` 容差；
- 外层跨折分组重叠：0。

这些结果验证了投影公式的实现正确性，但不证明该投影在本折被实际触发。

## 6. 方法有效性门

路由统计为：

| 路由 | 最小值 | 最大值 | 均值 | 标准差 | 六位小数唯一值数 |
|---|---:|---:|---:|---:|---:|
| OOS 候选门控 M2 | 0.1790 | 0.5830 | 0.4314 | 0.0609 | 1,689 |
| 无约束路由 M3 | 0.4514 | 0.9172 | 0.6879 | 0.1291 | 1,689 |
| 最终路由 M5 | 0.4514 | 0.9172 | 0.6879 | 0.1291 | 1,689 |

候选后验会降低目标概率的图像有 1,151 张，但 M5 相对 M3 的截断次数为 0；两者最大概率差为 0。M5 虽然明显区别于回退 M1，最大概率差为 0.069745，但没有区别于无约束路由 M3。

因此，本先导实验的判定为：

> **数学实现通过，方法有效性门未通过。**

失败原因不是数值错误，而是 `projector_stop` 上按安全 NLL 选择得到的 `epsilon_target = 0.08` 足以覆盖所有已学习路由的目标后验损失，使确定性安全投影在 Fold 0 外层退化为恒等映射。当前结果不足以把“目标安全投影实际改善了模型”写成论文结论。

## 7. 对后续研究的约束

1. 不直接启动原定三折正式运行，也不事后修改 v1 的网格和选择规则来美化 Fold 0。
2. Fold 0 结果保留为方法开发证据；任何结构升级都必须形成新版本协议。
3. 未触碰的 Fold 1 和 Fold 2 在新协议锁定前不得运行或查看外层结果。
4. 新结构必须把“何时保护目标、何时允许降低误入”写成网络可计算的条件，并证明相应性质。
5. 新结构至少要通过以下消融：无投影、仅后验下界、仅条件保护、完整双约束投影，以及无拒识版本。
