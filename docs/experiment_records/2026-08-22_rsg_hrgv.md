# RSG-HRGV experiment record (2026-08-22)

## Objective

Test whether directly supervising the HRGV reliability gate with sample-level expert regret improves routing quality and the final role-recognition trade-off. The study is limited to the fixed public-specimen image split; it is not an industrial sorting or grade-recovery experiment.

## Frozen method

For the true role `y`, define

```text
direct loss:  l_d = -log p_d(y|x)
mapped loss:  l_m = -log p_m(y|x)
regret gap:   Delta = l_m - l_d
soft target:  g* = sigmoid(Delta / T_r)
gap weight:   w = tanh(abs(Delta) / T_w)
gate loss:    L_reg = w * BCE(g, g*)
```

The frozen complete configuration uses:

- `lambda_gate_regret = 0.1`
- `regret_temperature = 0.2`
- `regret_weight_temperature = 0.5`
- soft targets and gap weighting
- stop-gradient expert evidence in the regret branch
- the same coupled residual-verifier HRGV inference graph used by the formal reference

The fixed formal seeds are `20260727`, `20260728`, and `20260729`.

## Pre-registered pilot gate

The complete RSG configuration advances to three-seed evaluation if any one of the following holds against the strictly matched HRGV reference:

1. Macro F1 improves by at least 0.5 percentage points without both intrusion metrics worsening.
2. One-right-one-wrong gate selection accuracy improves by at least 5 percentage points and mean routing regret falls by at least 10%.
3. Accuracy remains within 0.3 percentage points and the target-recall/risk trade-off improves.

## Preliminary mechanism trial

The first pilot isolated verifier gradients while the existing formal HRGV reference used coupled verifier features. Because this is not a strictly controlled comparison, its outputs are retained under `outputs/training/pilot_*` only as an implementation pretest and are excluded from model-selection claims.

## Strict controlled pilot

All five controlled configurations retain the formal HRGV verifier coupling and differ only in the registered RSG ablation.

| Configuration | Macro F1 | Target recall | Ti intrusion | Metallic intrusion | One-right gate selection | Mean routing regret |
|---|---:|---:|---:|---:|---:|---:|
| HRGV reference | 0.7494 | 0.7052 | 0.0815 | 0.1023 | 0.4384 | 0.1009 |
| RSG complete | 0.7456 | 0.7211 | 0.0774 | 0.1136 | 0.6000 | 0.0826 |
| RSG hard target | 0.7410 | 0.6813 | 0.0774 | 0.1193 | 0.4853 | 0.1071 |
| RSG unweighted | 0.7420 | 0.7171 | 0.0815 | 0.1193 | 0.6301 | 0.0824 |
| RSG coupled gate | 0.7405 | 0.7331 | 0.1018 | 0.1193 | 0.4426 | 0.0758 |

Against the strictly matched reference, complete RSG improved one-right-one-wrong gate selection by 16.16 percentage points and reduced mean routing regret by 18.15%. It therefore passed pre-registered criterion 2. The pilot does not establish a final performance gain: Macro F1 fell by 0.38 percentage points, target recall rose by 1.59 points, Ti intrusion improved by 0.41 points, and metallic intrusion worsened by 1.14 points.

The hard-target result supports retaining the continuous soft target. The unweighted result shows that raw gate-selection accuracy alone is insufficient because the final role metrics and intrusion trade-off can worsen. Allowing regret supervision to update expert/backbone evidence increased both intrusion rates, supporting local gradient isolation for this branch.

## Formal evaluation

Status: complete.

The formal comparison contains only the strictly matched HRGV reference and the frozen complete RSG configuration. Each is trained with the three fixed seeds. Conclusions are based on mean and sample standard deviation, paired cluster bootstrap intervals on the fixed test set, and the routing-specific metrics above.

| Configuration | Accuracy | Macro F1 | Target recall | Ti intrusion | Metallic intrusion | One-right gate selection | Mean routing regret |
|---|---:|---:|---:|---:|---:|---:|---:|
| HRGV reference | 76.48% ± 0.23% | 74.59% ± 0.34% | 72.38% ± 3.22% | 9.16% ± 1.13% | 11.55% ± 1.18% | 45.99% ± 4.82% | 9.86% ± 0.96% |
| RSG complete | 76.45% ± 0.98% | 74.76% ± 0.90% | 72.91% ± 1.38% | 8.42% ± 1.54% | 11.17% ± 0.87% | 58.01% ± 1.76% | 8.09% ± 0.17% |

The paired cluster Bootstrap comparison uses 2,000 replicates. The Accuracy, Macro F1, target-recall and two intrusion-rate intervals cross zero. Mean routing regret changes by `-1.77` percentage points (RSG minus HRGV), with a 95% interval of `[-2.86, -0.69]` percentage points and directional resampling probability `1.0000`. Thus the formal conclusion is restricted to the intended mechanism: RSG lowers the defined routing regret on this fixed public-specimen split. It does not establish a statistically significant overall classification gain or industrial sorting benefit.
