# OOS-RSG-HRGV 多专家确认实验协议

记录时间：2026-09-22。本文档在新专家训练前冻结，用于约束后续分析，避免根据最终评价结果改动方案。

## 1. 研究问题

现有单专家诊断表明，按重复组隔离的专家未见图像用于门控监督时，最终 NLL 和 Macro F1 相对专家已见监督呈一致改善方向，但三组门控初始化共享同一专家与同一停止集，不能构成独立多专家确认。本实验检验：

1. 样本外风险监督是否在三个从 ImageNet 初始化、独立训练的专家上重复降低最终校验后 NLL；
2. 样本外门控是否优于专家已见门控与无参数等权融合；
3. NLL 改善是否以不可接受的目标召回或困难负样本误入为代价。

## 2. 锁定数据协议

只使用原 `dataset_split_manifest.csv` 的训练行，并先按 `split_group_id` 保持重复/近重复组不可拆分，再在 17 个矿种-角色分层内进行确定性划分。原验证集和测试集不进入本实验。

| 功能子集 | 图像数 | 用途 |
|---|---:|---|
| `expert_fit` | 3,294 | 专家参数更新 |
| `expert_stop` | 599 | 专家轮次选择 |
| `gate_seen` | 597 | 专家已见监督对照；是 `expert_fit` 的组级子集 |
| `gate_unseen` | 597 | 样本外门控训练 |
| `gate_stop` | 597 | 门控轮次选择；专家和门控训练均不可见 |
| `final_eval` | 897 | 所有选择锁定后只读一次的最终评价 |

`gate_seen` 与 `gate_unseen` 的 17 个矿种-角色计数逐项相同；除 `gate_seen` 按设计属于 `expert_fit` 外，其余功能子集间图像组交叉均为 0。完整数据集共有 35 张钛磁铁矿图像；本协议只重划原训练集，其 17 张分布为专家清单 9 张、seen/unseen/gate-stop/final-eval 各 2 张。该数量不足以单独形成稳定的钛磁铁矿性能结论。

清单及哈希保存在 `outputs/training/oos_rsg_confirmation_manifests_v1/audit.json`。划分种子固定为 20260922，seen 匹配种子固定为 20260923。

## 3. 网络与训练锁定

专家网络保持 EfficientNet-B0 共享主干、直接角色专家、17 类矿种专家及固定矿种到角色映射、两类残差困难负样本校验器。专家不训练后悔门控损失，三个独立专家种子固定为：

```text
20260924, 20260925, 20260926
```

每个专家均从 ImageNet 权重开始，AdamW 学习率 `1e-4`、权重衰减 `1e-4`、batch size 16，最多 30 轮，patience 8，只按 `expert_stop` Macro F1 选取专家检查点。

冻结每个专家后，只训练一个新的风险门控。门控输入保持为共享特征、两专家不确定性与分歧特征，输出为直接角色专家权重：

\[
g_\phi(x)=\sigma(h_\phi(o_{\hat\theta}(x))),\qquad
p_{\mathrm{mix}}(x)=g_\phi(x)p_d(x)+[1-g_\phi(x)]p_m(x).
\]

困难负样本校验器作用后的最终后验记为

\[
p_f(x;\phi)=V_{\hat\theta}(p_{\mathrm{mix}}(x)).
\]

门控只最小化最终后验 NLL：

\[
\widehat R_G(\phi)=-\frac{1}{|D_G|}
\sum_{(x,y)\in D_G}\log p_{f,y}(x;\phi).
\]

seen 与 unseen 使用同一专家、同一门控初始化、同一批次顺序和超参数，仅替换门控监督来源。三个配对门控种子固定为 `20260934, 20260935, 20260936`，分别对应三个专家种子。AdamW 学习率 `1e-3`、权重衰减 `1e-4`、batch size 256、最多 30 轮，只按 `gate_stop` 最终 NLL 选取最早最优轮次。冻结专家参数和缓冲区必须逐项保持不变，专家梯度必须始终为空。

## 4. 预注册比较与判定

主要终点为 `final_eval` 上的最终 NLL。主要成对比较为：

1. `unseen gate - seen gate`，检验监督来源效应；
2. `unseen gate - equal fusion`，检验 OOS-RSG 路由是否优于无参数等权融合。

次要终点为 Macro F1、目标召回、含钛干扰误入目标比例和金属光泽干扰误入目标比例。每个终点保留三个独立专家种子的逐图预测，并按 `split_group_id` 进行成对簇 Bootstrap；跨种子汇总使用相同重采样索引，不能把 897 张图像当作彼此独立，也不能把三个门控初始化误称为更多专家。

只有同时满足以下条件，才把 OOS-RSG-HRGV 从候选机制提升为第一篇论文主方法：

- `unseen - equal` 的最终 NLL 平均差小于 0，且 95% 成对簇 Bootstrap 区间上界小于 0；
- 三个独立专家中至少两个方向一致；
- Macro F1 平均下降不超过 0.5 个百分点；
- 目标召回平均下降不超过 1 个百分点；
- 两类困难负样本误入目标比例的平均上升均不超过 1 个百分点。

若只满足 `unseen - seen` 而不满足 `unseen - equal`，结论限定为“样本外监督改善门控监督质量”，不得宣称新网络优于等权融合。若主要终点未满足，则保留条件无偏性与退化命题，但 OOS-RSG 仍只作为失败机制分析或后续方向。

## 5. 证据边界

最终评价仍来自公开矿物标本图像，不等价于真实矿石颗粒、工业皮带、品位、回收率或元素含量验证。样本切分和条件无偏风险估计属于标准统计工具；本文可能成立的贡献是把它们嵌入矿种-角色双专家、困难负样本校验和风险路由网络，形成可检验的样本外监督机制，而不是宣称一般性的样本切分理论首创。
