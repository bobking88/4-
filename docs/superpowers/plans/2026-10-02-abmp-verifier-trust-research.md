## 研究问题

冻结专家时，逐图校验可信度能否优于简单固定强度标定？只有这个问题获得支持，才进一步研究校验前间隔保护与全区间路由的网络耦合。停止集只有 2 张额外目标位于校验前而非校验后的完整区间，因此必须同时验证校验风险，不以这 2 张机会直接证明改进有效。

## 第一阶段 最小可证伪对照

固定既有 OOS 路由 g，不改变骨干和专家权重。令 p=gd+(1-g)m，原矛盾量为：

L=beta_t[(tau_t-v_t)/tau_t]_+ + beta_m[(tau_m-v_m)/tau_m]_+。

原尺度为 exp(-L)，研究尺度为 s=exp(-gamma L)，gamma∈[0,1]。

| 组别 | gamma | 目的 |
|---|---|---|
| A0 | 0 | 关闭校验的完整强对照 |
| A1 | 1 | 原固定校验对照 |
| A2 | 全局可学习标量 | 控制仅减弱/标定固定强度的收益 |
| A3 | 逐图小型可信度头 | 检验逐图表示是否带来额外收益 |
| A4 | 条件目标概率头 + 风险最优区间层 | 检验适当概率监督与解析选择的作用 |

A2 使用同一拟合/停止子集，但依据已推导凸性质仅从拟合集精确求解；A3/A4 以同一停止 NLL 选模。不得在看到结果后挑选较差标量对照，也不能把无校验版本排除以制造优势。

可信度头优先使用 18 维概率、分歧、不确定度和校验证据，不新增图像像素或来源标签。推理时不能使用真实标签、批次统计或测试集重归一化。每个模型的拟合只在 gate_stop_projector_fit，停止/选择只在 projector_stop；Fold 0 是已暴露开发数据，不报告为独立测试。

## 第二阶段 校验间隔约束

对指定的校验前目标锚点，采用附录 N 的 s_min 解析式。s_min<=1 时，令 s_hat=max(s,s_min)；否则报告不可行，不伪造保护。等效强度上限为 gamma_max=min(1,-log(s_min)/L)，仅在 L>0 且 0<s_min<=1 时使用，零量另作解析处理。

锚点仅依据推理时可得后验与预登记阈值定义。测试中必须分别统计真实、假目标锚点的数量、保持率与误入变化。解析性质保证预测间隔，不保证标签为真；不得将其称为总体召回保证。

## 进入独立确证前的门槛

第一阶段超参数与判据已在 `docs/experiment_protocols/abmp_verifier_trust_development_v1.json` 训练前冻结。后续扩大实验范围仍须新的协议；当前最低要求为：

- A3 或 A4 的收益超过 A0/A1/A2 中最强合格对照，而非只超过原未标定模型。
- 逐图强度确实非恒定；输出不能与最优标量或平均强度重放完全等价。
- A4 与 A3、平均强度重放有独立概率/风险差异；连续区间层是否超过两端点选择门，仍须补对照，不能把间隔保护或容量扩展写成已经验证。
- 同时报告 NLL、Macro F1、目标召回和两类难负样本误入，避免只选择改善的指标。
- 多随机种子开发用于排除偶然结果；独立 Fold 1/2 仅在整个方法冻结后运行，结果失败则保留负结果。

当前 A4 超过 A2 的开发 NLL，但幅度仅约 0.00113，且分类结果完全等于 A1。下一步先补同预算适应校准、端点门和可分离消融，明确概率风险收益的来源。若不能保持超过强对照的独立收益，不再叠加此类门。若研究目标需要提高召回，则转向学习互补的目标—难负样本残差表示；先审计残差是否扩大候选容量，再评价复杂网络。

2026-10-03 已完成不训练、不调参的同权重端点和原始概率重放。端点停止 NLL 为 0.845083±0.000370，略低于连续层 0.845140±0.000072，三个种子类别预测完全相同；当前不能主张连续层具有已验证的独有收益。移除区间层则 NLL 升至 1.010095±0.015707，目标召回降至 14.65%。这些是事后开发诊断，不修改旧门槛或晋级状态。

新增的理论分析将族内最优的结构性对数风险分为证据压缩、目标区间与固定非目标比例三项；实际已训练输出还多一项非负估计误差。固定证据和可行族时，学习校验强度只能降低估计项，不能降低结构下限。下一轮先补全局温度、Dirichlet 和同证据正温度网络等强对照，以及同目标概率头的 BCE/最终 NLL 分离。Dirichlet 须可靠求解，不能人为限制成未收敛弱基线。若这些对照消除 A4 的独立收益，转向额外视觉证据与互补残差表示，不继续包装普通校准为网络创新。详见 `docs/experiment_records/2026-10-03_verifier_theory_and_endpoint_audit.md`。新增训练范围仍需预登记和批准；Fold 1/2 及正式报告保持原边界。

2026-10-04 新增数学与只读容量审计：固定端点和非目标比例时，新增特征 H 的族内 oracle 风险收益等于目标条件互信息减去凸区间遗憾的 Jensen 增量，因而介于 0 和目标条件互信息之间；即使 H 含信息，同端点锁定时收益仍为 0。若允许学习非目标比例，可利用非目标内部的条件信息。这里不估计真实矿物互信息，也不保证有限网络收益。

## 精确等价核查对创新规格的修订

2026-10-06 只读审计证明双通道与普通 softmax 残差是逐点精确重参数化；使用同一潜变量头和确定性映射时，输出、相同损失及参数梯度一致。5000 个合成输出、128 个自动微分样本与既有 3400 行预测重建核验通过，不读取图片或视觉特征、不执行优化器步骤。普通线性 d 头与线性双通道头的固定参数函数族未被证明等价，不能混淆逐点输出能力与参数学习能力。

有限双预算对应目标 odds 区间与非目标成对比例约束的耦合凸多面体，不是简单固定概率盒。S_delta 包含于 F_delta,delta，后者包含于 S_2delta，且前一包含一般严格；因此相同数字的双预算与普通 span 不能称为同容量。几何凸性不意味着网络训练凸或风险改善。
