# 校验可信度与容量约束的后续研究计划

状态：依据已完成容量审计拟定的下一阶段方案；未训练新网络，不替代已确认的 ABMP v2 规格。

## 已完成的前置诊断

2026-10-02 已回读两子集冻结概率，完成未加权 NLL 的全局强度解析优化。OOS、固定融合、直接头、映射头的拟合集最优 gamma 都是 0，即关闭校验。OOS 停止集关闭校验 NLL 为 0.846273，原校验为 0.862188；但原校验 Macro F1 为 66.19%，高于关闭校验的 65.43%，含钛误入目标率也从 10.00% 降为 7.69%。不得将单个风险指标的改善写成全面优势。

另已推导“条件目标概率头 + 风险最优区间层”，其受限最终交叉熵超额风险不超过目标概率估计的 BCE 超额风险。这是待训练的候选设计，可作为逐图自由强度头的同预算对照；不替代已确认的 v2，不将通用校准或投影理论宣称为首次。详见 `docs/experiment_records/2026-10-02_abmp_conditional_risk_derivation.md`。

当前新增头的开发试验范围已提出确认，尚未训练。正式报告保持原版本，Fold 1/2 仍未为该候选方法开启。

## 研究问题

冻结专家时，逐图校验可信度能否优于简单固定强度标定？只有这个问题获得支持，才进一步研究校验前间隔保护与全区间路由的网络耦合。停止集只有 2 张额外目标位于校验前而非校验后的完整区间，因此必须同时验证校验风险，不以这 2 张机会直接证明改进有效。

## 第一阶段 最小可证伪对照

固定既有 OOS 路由 g，不改变骨干和专家权重。令 p=gd+(1-g)m，原矛盾量为：

L=beta_t[(tau_t-v_t)/tau_t]_+ + beta_m[(tau_m-v_m)/tau_m]_+。

原尺度为 exp(-L)，研究尺度为 s=exp(-gamma L)，gamma∈[0,1]。

| 组别 | gamma | 目的 |
|---|---|---|
| A0 | 0 | 关闭校验的完整强对照 |
| A1 | 1 | 原固定校验对照 |
| A2 | 全局可学习标量 | 控制仅减弱/标定固定强度的收益 |
| A3 | 逐图小型可信度头 | 检验逐图表示是否带来额外收益 |
| A4 | A3 加校验前间隔约束 | 检验解析约束的独立作用 |

A2 必须与 A3 使用相同的拟合、停止数据与预先登记的选模逻辑。不能在看到 A3 结果后挑选较差标量对照，也不能把无校验版本排除以制造优势。

可信度头优先使用 18 维概率、分歧、不确定度和校验证据，不新增图像像素或来源标签。推理时不能使用真实标签、批次统计或测试集重归一化。每个模型的拟合只在 gate_stop_projector_fit，停止/选择只在 projector_stop；Fold 0 是已暴露开发数据，不报告为独立测试。

## 第二阶段 校验间隔约束

对指定的校验前目标锚点，采用附录 N 的 s_min 解析式。s_min<=1 时，令 s_hat=max(s,s_min)；否则报告不可行，不伪造保护。等效强度上限为 gamma_max=min(1,-log(s_min)/L)，仅在 L>0 且 0<s_min<=1 时使用，零量另作解析处理。

锚点仅依据推理时可得后验与预登记阈值定义。测试中必须分别统计真实、假目标锚点的数量、保持率与误入变化。解析性质保证预测间隔，不保证标签为真；不得将其称为总体召回保证。

## 进入独立确证前的门槛

本文件不冻结具体超参数，实施前须完成独立协议文件与单元测试，记录允许的种子、选择预算和失败判据。最低要求为：

- A3 或 A4 的收益超过 A0/A1/A2 中最强合格对照，而非只超过原未标定模型。
- 逐图强度确实非恒定；输出不能与最优标量或平均强度重放完全等价。
- A4 相对 A3 具有独立约束激活及性能/风险作用，否则间隔层不作为方法贡献。
- 同时报告 NLL、Macro F1、目标召回和两类难负样本误入，避免只选择改善的指标。
- 多随机种子开发用于排除偶然结果；独立 Fold 1/2 仅在整个方法冻结后运行，结果失败则保留负结果。

若 A2 已解释全部改进，应结论为校验标定有效而非网络创新成立。若没有校验可信度收益，不再叠加此类门，转向学习互补的目标—难负样本残差表示；先审计残差是否扩大候选容量，再评价复杂网络。

## 理论贡献边界

候选可行区间、共享校验的重新参数化、单向校验集合性质及最小尺度条件，为网络结构选择提供解析依据。它们不是“首次凸投影理论”；后续论文的方法贡献必须建立在超过强对照的独立结果及与相关工作的全文比较上。阶段条件决策、送检经济代价和工业品位验证仍保留为 C 路线后续研究，不由当前 RGB 代理数据虚构。
