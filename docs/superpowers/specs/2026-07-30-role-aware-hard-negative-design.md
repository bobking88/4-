# 角色感知困难负样本学习设计说明

## 研究目标

在现有公开矿物标本图像四分类基线上，完成可复现的三项补强：

1. 形成目标代理类/非目标类的业务指标；
2. 补齐加权 Focal Loss 的三随机种子对照；
3. 实现并验证角色感知困难负样本学习，为论文提供范围可控的方法改进。

## 不纳入当前研究的内容

- 不把公开标本图像结果解释为工业分选回收率、精矿品位或现场部署性能。
- 不基于缺失的工艺阶段、物料流、成本或化验数据构造阶段决策理论。
- 不将 magnetite 代理样本的性能解释为钛磁铁矿独立识别性能。

## 方法设计

共享 EfficientNet-B0 主干网络，训练时输出两个任务：

- 主任务：现有四分类，类别为目标矿物、含钛干扰、脉石/废石、金属光泽干扰；
- 辅助任务：目标代理类/非目标类二分类。

在主任务交叉熵与辅助二分类交叉熵基础上，对指定的高风险类别对使用监督对比约束：

- `target_mineral` 与 `ti_bearing_negative`；
- `target_mineral` 与 `metallic_hard_negative`。

同一四分类标签样本作为正对；上述两类跨标签样本作为重点负对；其他跨类对不额外施加关系约束。总损失为：

`L = L_four_class + lambda_binary * L_target_binary + lambda_contrast * L_role_contrast`。

## 实验矩阵

固定数据版本与划分，使用随机种子 `20260727`、`20260728`、`20260729`：

| 设置 | 三随机种子 | 目的 |
| --- | --- | --- |
| ResNet50 + 加权交叉熵 | 已完成 | 经典基线 |
| EfficientNet-B0 + 加权交叉熵 | 已完成 | 主基线 |
| EfficientNet-B0 + 加权 Focal Loss | 补齐 | 判断损失函数结论的稳定性 |
| EfficientNet-B0 + 角色感知困难负样本学习 | 新增 | 验证方法改进 |

## 评价

除既有 Accuracy、Macro F1 和分类召回率外，新增折叠二分类指标：

- 目标代理类 Precision、Recall、F1；
- 目标代理类漏选率；
- 含钛干扰误入目标类比例；
- 金属光泽干扰误入目标类比例；
- 各指标的三随机种子均值和样本标准差。
