# 分层矿物识别与开放集风险研究设计

## 目标

在已完成的四分类基线、Focal Loss 和角色感知困难负样本实验基础上，形成可服务结题报告并可延伸为首篇论文的方法主线：以矿物种类监督辅助选矿角色识别，并以开放集拒识和风险约束作为后续验证，而不把缺少流程数据支撑的阶段条件化决策图写成当前结论。

## 已确认边界

- 数据固定为 `dataset_final_v1` 的 8,529 张公开矿物标本图像；现阶段不以 RGB 图像预测 V、Ti、Fe 品位、回收率或工业分选效果。
- 保留四类选矿角色：`target_mineral`、`ti_bearing_negative`、`gangue_negative`、`metallic_hard_negative`。
- 使用清单中的 17 个 `mineral_label` 作为细粒度物种监督；物种标签到角色标签的映射必须由训练前验证，禁止从模型预测中反推映射。
- 主干网络沿用 ImageNet 预训练 EfficientNet-B0，使新增实验能够与已有结果直接比较。
- 角色感知困难负样本关系仅包括目标矿物与含钛干扰、金属光泽干扰；不为缺少工艺数据的错误虚构经济代价矩阵。
- 开放集实验只在取得独立未知矿物图像及清单后运行；当前先实现可接入未知集的评估接口。

## 方法设计

模型以 EfficientNet-B0 提取共享视觉特征，并输出四类角色 logits、17 类矿物种类 logits、目标/非目标 logits 和 128 维对比表征。矿物种类后验经固定映射矩阵聚合为角色后验，并与直接角色头的后验进行 KL 一致性约束。总损失为：

`L = L_role + alpha * L_species + beta * L_consistency + gamma * L_binary + eta * L_hard`

其中 `L_hard` 仅分离目标矿物与两类关键困难负样本。模型报告总体 Accuracy、Macro F1、各角色召回率、目标代理 F1、目标漏选率、含钛干扰误入目标率和金属光泽干扰误入目标率。

## 实验顺序

1. 建立可测试的矿物种类索引、种类到角色映射和概率聚合函数。
2. 实现分层训练器，并运行最小 smoke test。
3. 以 20260727、20260728、20260729 三个种子完成正式训练，生成固定格式的指标与逐图预测。
4. 对四分类基线、二分类辅助、困难负样本和完整分层模型做组件对照；若运行资源允许，全部采用三随机种子。
5. 更新图表生成脚本和技术报告，加入模型结构、损失函数、结果取舍和与两篇重点论文的差异。
6. 实现未知集的 MSP、Energy、特征距离/OCSVM 评估接口；未知矿物数据下载、审核和正式开放集实验作为下一批任务。

## 结题与论文表述

结题报告可确认的贡献是：可追溯的数据治理、选矿角色四分类任务、角色感知困难负样本原型，以及后续的分层一致性实验结果。论文拟聚焦“选矿角色分层识别、关键困难负样本约束和开放集风险控制”。阶段条件化选矿决策图只作为后续研究：须先由选矿专家确认矿物—流程阶段—动作映射，并提供真实阶段、品位、回收率或送检成本等数据。
