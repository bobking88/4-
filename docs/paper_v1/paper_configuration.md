# 第一篇论文配置记录（v1）

## 1. 论文定位

- 论文类型：方法与应用结合的实验研究论文。
- 研究对象：公开矿物标本图像中的钒钛矿相关矿物。
- 核心任务：将矿物种类证据、选矿角色证据与困难负样本风险结合，完成四类选矿角色识别。
- 当前主线：跨粒度后悔监督门控验证网络（RSG-HRGV-Net）。
- 后续方向：阶段条件化选矿决策图。该方向需要真实流程阶段、矿物—动作映射、品位/回收率和送检成本数据，不作为第一篇论文的已验证贡献。
- 证据范围：公开标本图像上的视觉代理验证，不等同于钒钛矿品位预测、回收率验证或工业在线分选。

## 2. 暂定题目

中文题目：

> 面向钒钛矿相关矿物视觉角色识别的跨粒度后悔监督门控验证网络

英文题目：

> Cross-Granularity Regret-Supervised Gated Verification for Visual Role Recognition of Vanadium-Titanium-Magnetite-Related Minerals

备选中文题目：

> 基于跨粒度证据路由与困难负样本验证的钒钛矿相关矿物图像识别

## 3. 研究问题

1. 直接选矿角色分类与细粒度矿物种类分类能否提供互补的跨粒度证据？
2. 能否根据共享特征、两路熵和 Jensen-Shannon 分歧学习样本级融合权重？
3. 训练期的真值类专家损失差能否形成可检验的软后悔门控监督，并降低预定义的路由后悔？
4. 针对含钛干扰和金属光泽干扰的验证器，如何在降低误入目标风险与保持目标召回之间呈现可解释取舍？
5. 后悔上界、软目标逼近和后悔分支局部梯度隔离能否在固定测试、摄影者留出和第二 CNN 主干上得到相互印证？

## 4. 可写入摘要的主要结果

- 数据集共 8,529 张图像，固定划分为训练集 5,961 张、验证集 1,284 张、测试集 1,284 张。
- RSG-HRGV-Net 三随机种子 Accuracy 为 76.45% ± 0.98%，Macro F1 为 74.76% ± 0.90%；该模型相对 HRGV 的总体分类指标成对区间均跨 0。
- RSG 相对匹配 HRGV 的平均路由后悔降低 1.77 个百分点，95% 成对簇 Bootstrap 区间为 [−2.86, −0.69] 个百分点；摄影者留出时降低 3.53 个百分点，区间为 [−4.75, −2.17] 个百分点。
- 在严格匹配的 ResNet50 三随机种子确认中，RSG 的平均路由后悔降低 3.33 个百分点，区间为 [−4.86, −1.98] 个百分点；此结果只支持融合层路由机制的跨主干经验确认，不支持任意主干上的性能保证。
- 角色感知对比约束仍是总体分类性能最清晰的组件证据：完整 HRGV 相对无该约束版本的 Accuracy 提高 1.09 个百分点，95% 区间为 [0.08, 2.15]；Macro F1 提高 1.08 个百分点，区间为 [0.12, 2.06]。
- 9 次高精度检查点重放覆盖 10,242 张图像；凸融合精确分解最大绝对残差为 8.44e-7，B.1 和 B.2 最大残差分别为 9.41e-8、5.94e-8，在 2e-6 容差下三者违反计数均为 0。

## 5. 创新贡献的正式表述

1. 面向钒钛矿相关矿物的四角色视觉代理识别，提出由直接角色专家、矿物种类专家、后悔监督门控和双困难负样本验证器组成的 RSG-HRGV-Net。
2. 以真值类专家损失差构造软最优门控目标，并用有界差距权重强调高路由风险样本；该监督分支对专家后验停止梯度，从而显式区分“学习专家”与“学习路由”。
3. 给出凸融合路由后悔的精确分解与上界、软目标对硬最优门控的指数逼近和后悔分支局部梯度隔离，并以逐图局部上界、软硬偏差分层和高精度重放验证公式与实现的一致性。
4. 采用三随机种子、固定测试、摄影者整体留出、ResNet50 主干替换、成对簇 Bootstrap 和组件消融，严格区分路由机制改善、总体分类性能和两类困难负样本风险的证据强度。

## 6. 禁止使用的表述

- 首次使用深度学习识别钒钛矿。
- 首次提出层级分类、门控融合、对比学习、拒识或多网络融合。
- 已实现钒钛矿品位检测、精矿品位预测、工业在线分选或未知矿物拒识。
- RSG-HRGV 全面或显著提高总体 Accuracy、Macro F1 或全部风险指标。
- 普通磁铁矿样本可以等同于钛磁铁矿真实样本。
