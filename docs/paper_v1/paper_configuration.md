# 第一篇论文配置记录（v1）

## 1. 论文定位

- 论文类型：方法与应用结合的实验研究论文。
- 研究对象：公开矿物标本图像中的钒钛矿相关矿物。
- 核心任务：将矿物种类证据、选矿角色证据与困难负样本风险结合，完成四类选矿角色识别。
- 当前主线：层级风险门控验证网络（HRGV-Net）。
- 后续方向：阶段条件化选矿决策图。该方向需要真实流程阶段、矿物—动作映射、品位/回收率和送检成本数据，不作为第一篇论文的已验证贡献。
- 证据范围：公开标本图像上的视觉代理验证，不等同于钒钛矿品位预测、回收率验证或工业在线分选。

## 2. 暂定题目

中文题目：

> 面向钒钛矿相关矿物识别的层级风险门控验证网络

英文题目：

> Hierarchical Risk-Gated Verification Network for Visual Recognition of Vanadium-Titanium-Magnetite-Related Minerals

备选中文题目：

> 基于层级证据融合与困难负样本验证的钒钛矿相关矿物图像识别

## 3. 研究问题

1. 直接选矿角色分类与细粒度矿物种类分类能否提供互补证据？
2. 能否根据两个专家的熵与分歧学习样本级融合权重？
3. 针对含钛干扰和金属光泽干扰的验证器，能否降低其误入目标类的风险？
4. 角色感知对比约束能否稳定改善总体识别性能？
5. HRGV 输出能否支持风险—覆盖率分析和带拒识的选择性决策？

## 4. 可写入摘要的主要结果

- 数据集共 8,529 张图像，固定划分为训练集 5,961 张、验证集 1,284 张、测试集 1,284 张。
- HRGV-Net 三随机种子 Accuracy 为 76.48% ± 0.23%，Macro F1 为 74.59% ± 0.34%。
- 相对无角色感知对比约束的版本，Accuracy 提高 1.09 个百分点，95% 成对簇 Bootstrap 区间为 [0.08, 2.15]；Macro F1 提高 1.08 个百分点，区间为 [0.12, 2.06]。
- 相对既有分层 EfficientNet-B0，HRGV 的 Accuracy 和 Macro F1 均值分别提高 1.06 和 1.18 个百分点，含钛干扰和金属光泽干扰误入目标类的比例分别下降 1.77 和 2.84 个百分点；目标召回下降 5.18 个百分点，主要区间跨 0。
- 两个困难负样本验证器的 ROC-AUC 约为 0.91 至 0.92。

## 5. 创新贡献的正式表述

1. 面向钒钛矿相关矿物的选矿角色识别，提出由直接角色专家、矿物种类专家、样本级可靠性门控和双困难负样本验证器组成的 HRGV-Net。
2. 提出带中性区的残差后验校正，使支持证据区域保持恒等，并在验证器给出反对证据时单调降低目标类相对赔率。
3. 给出凸融合对数损失上界、残差校正恒等性与单调性、严格验证式接纳误收上界、带拒识的贝叶斯最优规则和验证器梯度隔离五项性质，并逐项标明假设和适用边界。
4. 采用三随机种子、固定测试集、成对簇 Bootstrap 和组件消融，量化总体性能、目标召回与两类困难负样本误入之间的取舍。

## 6. 禁止使用的表述

- 首次使用深度学习识别钒钛矿。
- 首次提出层级分类、门控融合、对比学习或拒识。
- 已实现钒钛矿品位检测、精矿品位预测或工业在线分选。
- HRGV 全面或显著优于所有基线。
- 普通磁铁矿样本可以等同于钛磁铁矿真实样本。

## 7. 稿件配置

- 语言：先完成中文稿，再形成英文稿。
- 结构：IMRaD（引言、相关工作、材料与方法、实验、讨论、结论）。
- 引用：中文初稿暂按顺序编码制组织；选定期刊后统一到目标格式。
- 目标期刊：待根据稿件完成度在矿物加工、矿业工程、地学人工智能或工程信息类期刊中选择。
- 数据开放：公开代码、数据清单、划分和结果；原始 Mindat 图像受来源许可约束，不在仓库直接分发。
- 强制声明：数据可用性、利益冲突、基金、作者贡献、研究局限和 AI 工具使用说明。
