**一句话主张：** 在公开矿物标本的四角色代理识别任务中，跨粒度后悔监督降低了已定义的路由后悔；条件推导和负结果同时说明，这不等于稳定提高最终分类性能。

## 2. 术语与单位

| 固定写法 | 含义 | 不采用的混写 |
|---|---|---|
| RSG-HRGV-Net | Regret-Supervised Hierarchical Risk-Gated Verification Network | 不把它写成新的卷积骨干 |
| direct role expert / species-to-role expert | 直接四角色专家 / 十七矿种映射专家 | 不称两个独立预训练主干 |
| target proxy role | 当前数据定义的目标代理角色 | 不等同含钒品位或真实钛磁铁矿鉴定 |
| routing regret | 相对真实类概率 oracle 的验证前对数损失差，单位 nat | 不写百分比、百分点或分类后悔 |
| probability-oracle agreement | 在恰有一个专家分类正确的子集内，与概率 oracle 的硬门控一致率 | 不等同选中分类正确专家的比例 |
| hard expert-choice accuracy oracle | 利用真值选取两个专家中分类正确者的诊断量 | 不称所有连续融合的准确率上界 |
| percentage points | 准确率、召回率等百分数的差值单位 | 不用于 NLL 差值 |
| photographer holdout | 同一图片生态内的摄影者留出 | 不等同跨矿山、工业现场或未知矿物 OOD |

| 主张 | 已有支撑 | 状态与边界 |

## 5. 投稿前必须完成，但不需要新实验

1. **历史配置一次性追溯。** 只查已有命令、运行日志和环境说明，寻找 batch size、优化器、学习率、权重衰减、输入变换、早停、硬件与训练源码身份；不得用当前默认值补写。找不到的字段保持披露，并判断缺口是否足以妨碍审稿复现。不能把“缺失已披露”当作问题已经解决。
2. **基线与引用收口。** 从既有汇总补成一张标准 CNN/已完成方法的比较表，逐项核对划分与指标可比性；没有配对证据不补显著性。当前英文稿已包含匹配 HRGV 对照与消融，但尚不是最终全基线表。补齐已实际采用方法的原始出处，作者须确认阅读与引用准确性；不扩展算法查新或训练。
3. **作者事实。** 提供署名、单位、通讯作者、基金及编号、CRediT、利益冲突、数据再分发限制、AI 辅助范围与人工审核说明。未知处保留占位，不替作者作“无资助”“无冲突”“全部作者已批准”的声明。
4. **完成投稿格式。** 英文语义复核后做一次 Word/LaTeX 排版；公式保持可编辑，检查四张图与表格、交叉引用、独立补充文件和投稿信。当前没有生成或宣称已经检查最终版 PDF。
5. **冻结并决定是否提交。** 核验可公开文件清单、固定 release/commit，确认学校认可口径、APC 预算及全体作者同意，再由作者决定实际投稿。若关键复现缺口仍无法交代，应先完成审稿风险评估，不为了赶投稿填造细节。

上述是有限收稿顺序，不是新的实验计划。阶段决策、未知矿物、真实矿石外部验证和 MSB 等候选不作为本轮完成条件。文稿表达可以使证据更清楚，但不能把未成立的网络优势变成已验证创新。
