# 第一篇论文详细大纲与证据映射（v1）

## 1. 论文逻辑主线

公开矿物标本图像具有类内差异大、伴生矿物混杂、背景异构和细粒度标签不完全可靠等特点。现有四分类基线的主要错误并非均匀分布，而集中在目标矿物与含钛干扰、目标矿物与金属光泽干扰之间。HRGV-Net 建立了层级证据与困难负样本验证基础；RSG-HRGV-Net 进一步聚焦“在两路既有证据分歧时如何学习路由，并量化选择错误的后悔”。

论文叙事顺序为：

> 数据治理与失效分析 → 层级双专家 → 后悔监督可靠性门控 → 双验证器残差校正 → 可证明路由性质 → 跨划分/跨主干复核 → 风险取舍与适用边界

## 2. 详细大纲

### 摘要

按“背景—问题—方法—结果—结论”五句群组织。不得使用工业回收率或品位表述。结果只写有明确统计来源的数字。

### 1 引言

1. 钒钛磁铁矿资源综合利用对矿物识别与分选决策的需求。
2. RGB 图像只能提供颜色、光泽、形态与基质等外观证据，不能替代 XRD、SEM-EDS、XRF 或化学分析。
3. 现有通用矿物识别、钒钛矿视觉二分类、铁矿图像融合识别和 OOD 矿物识别的进展。
4. 研究缺口：公开异构标本图像中的选矿角色识别，以及目标类与两类困难负样本之间的非对称风险。
5. 本文研究问题与四项贡献。

### 2 相关工作

#### 2.1 矿物和矿石图像识别

覆盖 CNN、Transformer、细粒度识别、多标签识别和 Mindat 数据。普通模型比较、注意力模块、Focal Loss 和一般多任务学习只作为已有方法。

#### 2.2 钒钛矿与铁矿视觉识别

正面比较宁金研究和最接近的铁矿六分类/多视图融合工作，明确任务、数据和评价条件不同。

#### 2.3 开集识别与选择性决策

引用矿物 OOD 论文和通用选择性分类理论。本文不宣称首次提出 OOD 或拒识，而是将其用于 HRGV 后验的风险分析。

#### 2.4 研究缺口

收束到三个缺口：层级证据可靠性、困难负样本误入目标风险、公开标本条件下的可审计统计验证。

#### 4.1 共享主干与层级双专家

使用 EfficientNet-B0，给出 $h=f_\theta(x)$、$p_d$、$p_s$ 和 $p_m=Ap_s$。

#### 4.2 样本级可靠性门控

给出归一化熵、Jensen-Shannon 分歧、门控 $g(x)$ 和融合后验 $p_f$。

#### 4.3 双困难负样本验证器

分别建模目标—含钛干扰和目标—金属光泽干扰，说明掩码二分类训练集合。

#### 4.4 中性区残差后验校正

给出 $c_h(v_h)$、$\eta(x)$ 和最终后验 $q$。强调只修改目标相对赔率，保持非目标类相对顺序。

#### 4.5 角色感知对比约束与完整损失

给出总损失及所有系数，说明其与一般 Focal Loss 的区别。

#### 4.6 八项理论性质与路由诊断

1. 凸融合对数损失上界。
2. 中性区残差恒等性与目标赔率单调性。
3. 严格验证式目标接纳误收上界。
4. 带拒识的贝叶斯最优选择性决策。
5. `stopgrad` 条件下的验证器梯度隔离。

6. 真值类更优专家相对融合概率的路由后悔上界（B.1）。
7. 软后悔目标对硬最优门控的指数逼近（B.2）。
8. 后悔监督分支的局部梯度隔离（B.3）及其逐图局部上界推论。

每项均按“命题—假设—证明—实验对应—不能推出什么”组织。

### 5 实验设计

#### 5.1 实现细节

#### 5.4 统计方法

三随机种子报告均值与样本标准差。固定测试集上的模型比较使用成对簇 Bootstrap；簇以去重/来源分组为单位。可补充 exact McNemar，但不能把三随机种子均值差直接写成显著差异。

#### 5.5 RSG 机制确认与增强实验

- 软目标、硬目标、无差距加权与取消局部梯度隔离的门控消融。
- 摄影者来源留出测试和严格匹配的 ResNet50 主干替换确认。
- B.1 局部上界、B.2 软硬偏差的分层诊断和高精度数值重放。
- 普通磁铁矿代理消融、风险—覆盖率与温度校准。
- 独立未知矿物 OOD 协议（下一阶段补齐，不作为当前核心结论）。

### 6 结果

#### 6.1 基线结果

报告 ResNet50、EfficientNet-B0 和 Focal Loss 三随机种子结果。

#### 6.2 HRGV 基础结果与风险取舍

#### 6.3 RSG 路由机制与组件贡献

#### 6.4 与分层模型的比较

同时报告总体性能提升、两类误入下降和目标召回下降，避免只挑有利指标。

#### 6.5 选择性识别与校准

### 7 讨论

1. 为什么对比约束的证据最清晰。
2. 为什么验证器降低误入时可能损失目标召回。
3. 为什么公开标本测试不能代表工业传送带。
4. Mindat 主标签、伴生矿物和背景偏差的局限。
5. 钛磁铁矿样本量有限及普通磁铁矿代理的边界。
6. 阶段条件化选矿决策图作为后续研究，需要哪些真实数据。

### 8 结论

只总结已验证贡献，不引入新主张。结论应同时写出性能、风险取舍和应用边界。

## 5. 下一阶段实验门槛

第一篇论文仍需优先补齐独立 OOD 测试集和统一开集协议。未知矿物必须与四类训练矿物在物种层面不重叠，并记录来源、许可、标签依据和图像质量。至少报告 AUROC、AUPR、FPR95、已知样本保留准确率以及目标类误接纳率。

若无法获得可靠 OOD 数据，论文应将开集识别降为扩展实验，不得写入标题或核心贡献。
