## 复核与重建

`build_errata.py`仅为文档构建脚本，读取勘误前报告、已归档汇总和既有图件，不导入模型。脚本要求源报告SHA匹配，且固定输出目录不存在；不能在当前正式版上重复执行或覆盖旧目录。

需要重建时，在独立临时检出中将勘误前备份作为源文件，使用包含`python-docx`、`lxml`、`matplotlib`的文档运行环境执行构建，再用Word或兼容渲染器更新字段并导出PDF，执行`verify_layout.py`并检查所有页面。Word版本、字体及保存元数据可能改变二进制哈希；内容与结构仍须核验，不能仅依赖脚本退出码。

`verify_layout.py`会将视觉检查标记重置为`pending`，因为自动检查不代表已看过新渲染。当前完成状态对应上述固定哈希，后续重建须重新完成视觉核对。QA PDF、页面PNG和本地依赖不作为正式交付件上传。
