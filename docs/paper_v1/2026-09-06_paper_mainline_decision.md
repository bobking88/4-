# 第一篇论文主线与网络创新证据决策

日期：2026-09-06。适用范围：公开矿物标本图像上的钒钛矿相关四角色视觉代理任务。

## 1. 决策

第一篇论文的主方法确定为 **RSG-HRGV**（角色感知分层门控验证网络），而不是 CGDC、RPG、M-RPG 或 PHR 的任一扩展版本。核心理由不是“RSG 的分数绝对最高”，而是它在当前数据条件下形成了最完整且可辩护的证据链：固定的矿物种类—角色映射、双专家后验、门控融合、路由遗憾分析、三随机种子正式实验、摄影者来源留出验证、重复图片受控与逐图预测审计。

论文必须把它定位为：**公开异构矿物图像中面向钒钛矿相关角色识别的分层视觉代理方法**。它不预测 V/Ti/Fe 品位，不替代化验或显微矿相鉴定，也不等价于工业分选回收率。

## 2. 网络创新的可写范围

设共享视觉特征为 \(h=f_\theta(x)\)，直接角色专家后验为 \(p_d\)，17 类矿物种类专家后验为 \(p_s\)，固定种类到角色的线性映射为 \(M\)，则

\[
p_m=Mp_s,\qquad p_f=g(x)p_d+[1-g(x)]p_m,\qquad g(x)\in[0,1].
\]

RSG-HRGV 的可写理论点是：细粒度物种证据经 \(M\) 聚合为选矿角色证据；在两个专家预测不一致且至少一个正确的受限集合上，门控可用路由遗憾刻画相对较优专家的额外损失。对给定的两个专家后验，这是一个可验证的计算图性质和代理分析工具，不是“首次提出混合专家”或“必然提高准确率”的一般定理。

最稳妥的贡献链为：

1. 按钒钛矿相关视觉角色组织任务，并保留矿物种类—角色映射，以处理“种类细粒度、决策粗粒度”的不一致；
2. 使用种类映射专家与直接角色专家的门控融合，给出路由遗憾、概率一致性和专家互补性的可审计定义；
3. 以重复/近重复受控、固定测试集、三随机种子和摄影者留出共同约束结论，不将公开标本图像的随机测试结果表述成工业效果。

## 3. 候选扩展的结论

| 候选网络 | 当前证据 | 在第一篇论文中的位置 |
|---|---|---|
| CGDC-RSG-HRGV | 三随机种子实验未显示稳定整体优势 | 受控探索/附录，不作主性能结论 |
| RPG-HRGV | 分区熵有明确链式分解，但整体指标未形成稳定优势 | 受控探索/附录 |
| M-RPG-HRGV | 容量归一化与单调门控性质可证明；目标类召回有趋势，但 Macro F1 与扩展验证均不足以支持稳定优越性 | 理论候选与消融，不作主性能结论 |
| PHR-Routing-Net | 验证集八项预注册筛选未晋级：局部成对遗憾下降，但 Macro F1、目标类召回和关键误入率未改善 | 机制性负结果，保留公式、网络图与边界分析 |

截至本记录，继续在相同冻结划分上尝试更多门控、注意力或损失变体只会增加验证集选择偏差。除非重新预注册独立数据划分与一个明确的全局风险目标，否则不再将新网络变体作为第一篇论文的性能候选。

## 4. 当前应完成的论文与报告工作

1. 将技术报告的主体收束为数据治理、任务定义、ResNet50/EfficientNet-B0 基线、RSG-HRGV、来源留出和边界说明；已失败的候选扩展放入附录或后续工作。
2. 在论文方法部分给出 \(p_m=Mp_s\)、门控融合、路由遗憾和一致性约束的公式，并明确每个命题的条件与不推出的结论。
3. 实验部分优先报告：随机固定测试、摄影者留出、目标类漏检率、Ti/金属光泽误入目标比例、模型校准与误差样本；报告三随机种子均值和标准差，以及按 `split_group_id` 聚类的统计比较。
4. 文献对比中正面讨论 Mindat 图像的伴生矿物、代理磁铁矿和来源泄漏风险；不以普通 CNN 排名作为创新点。

## 5. 第二阶段研究的必要条件

真正更强的网络理论创新应进入第二阶段，并先补充新信息，而不是从同一 RGB 标本数据中继续挖掘：

1. 收集独立的真实矿石颗粒或受控实拍图像，并由矿物加工/地质人员确认标签；
2. 按矿区、摄影者、成像设备或批次建立来源外划分；
3. 在专家确认的“矿物—流程阶段—处理动作”映射和合理代价矩阵基础上，研究阶段条件化风险决策与拒识/送检；
4. 对新方法在未参与设计的来源留出或外部集上预注册比较，才讨论其是否具有经验优势。

这个阶段才适合把“阶段条件化选矿决策图”作为理论研究对象。没有真实流程阶段、品位、回收率、物料流或送检成本数据时，它只能作为后续研究路线，不能被反向写成当前实验已经完成的创新。
