## 两处语义更正的源码依据

只读核对以下已归档源码，没有执行其中函数，也未读取它们指向的预测文件。

1. `scripts/train_hrgv_mineral_classifier.py`中，`final_predictions`来自`outputs["final_role_probabilities"]`的argmax，随后作为`final_prediction_ids`传给记录构造器。`scripts/analyze_rsg_hrgv_experiment.py:calculate_routing_metrics`以记录的`predicted_label`计算`fused_accuracy`。因此本图将此历史字段标为“Final RSG prediction”，而不是验证前凸融合$p_f$的Accuracy。
2. `scripts/hrgv_network.py:gate_routing_diagnostics`把`hard_oracle_gate`定义为两专家真值类概率比较，并把`hard_gate_selection_correct`定义为该oracle与`gate>=0.5`的一致性。分析器再仅在恰有一位专家分类正确的子集上取均值。因此该值是条件概率oracle一致率，不能直接等同于选择分类正确专家的比例。

记$S$为恰有一位专家argmax分类正确的样本集，则展示量的口径为

\[
A_{g\mid S}=|S|^{-1}\sum_{i\in S}
\mathbf1\{\mathbf1[g_i\ge0.5]=g_{o,i}\}.
\]

$g_o$由真值类概率比较定义，有限精度下沿用源码的概率截断。图7的硬专家二选一oracle准确率则来自两专家分类正确事件的并集，二者不可混同。上述内容是指标定义更正，不是新理论命题。
