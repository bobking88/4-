## 5. 理论机制的预定核验

| 命题/问题 | 必留证据 | 可证伪限制 |
| --- | --- | --- |
| P1 恒等起点与真实微分 | 初始 q 与锚点差、参照冻结/无别名/哈希；初始及实际参数 Jacobian；前五次更新前的数据/正则/总梯度完整向量及参数布局 | 恒等值不表示零微分；真实零梯度不换种子或扰动输入，不能保证数据梯度非零 |
| P2 双预算稳定 | 逐样本分支/主特征/u/v 界、输出包络、NLL/KL；实际读出谱范数、证书值、同权重 adaptation-off 概率与保护覆盖 | off 不等于 T0 或另训 U；界成立不保证标签正确、召回更好或证书实用 |
| P3 起点标量分支核 | 初始输入顺序、路由、J/Gram、奇异值；固定绝对数值秩阈值 1e-10；实际训练后 Jacobian | Jmain=G Jaux、Kmain=G Kaux G 仅在共同零适配起点；不推广至全参数联合核或全训练过程 |
| 角色分支真实作用 | 各点 delta 范数/余弦、参数与参照距离、固定状态逐分支移除与 adaptation-off 的概率/决策变化 | 仅推理消融，不重训；梯度/核迹较大不证明增量纠错 |

P2 主路径比较的上界为
\[
|\log q_y-\log q_y^{\rm off}|\leq
(\bar\alpha+\bar\beta)\varepsilon_f L_F b^2,\quad
L_F=(1+e^{-1})\|W_2\|_2\|W_{1,h}\|_2.
\]
辅助路径相应证书将 b^2 换为 b。界违规容忍度固定为 1e-10+1e-10*abs(bound)；初始恒等绝对容忍度 1e-12。P3 正定/严格正路由条件不成立时不报告最小特征值下界，保留真实奇异核。有限差分已有固定方向/1e-6 步长的合成证据，本轮不增加真实数值探查网格或重跑合成计时。

\[
N_+=\sum_{i:y_i=T}\mathbf1[\hat y_i^{R}=T,\hat y_i^{U}\ne T],\quad
N_-=\sum_{i:y_i=T}\mathbf1[\hat y_i^{R}\ne T,\hat y_i^{U}=T].
