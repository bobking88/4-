# RSG-HRGV 第一篇论文主线与证据蓝图

## 1. 论文定位

**推荐中文题目**：面向钒钛矿相关矿物视觉角色识别的跨粒度后悔监督门控验证网络

**推荐英文题目**：Cross-Granularity Regret-Supervised Gated Verification for Visual Role Recognition of Vanadium-Titanium-Magnetite-Related Minerals

**研究问题**：在公开矿物标本图像的固定四角色闭集任务中，直接预测角色的视觉证据与由细粒度矿物种类聚合得到的角色证据会出现逐样本分歧。如何在不使用推理阶段真实标签、不改变两路专家本身证据的前提下，训练一个可解释的门控模块，使其更接近真值条件下概率更优的专家，并量化其选择错误导致的后悔？

**任务边界**：本文研究 Mindat 公开标本图像的 `target_mineral`、`ti_bearing_negative`、`gangue_negative` 和 `metallic_hard_negative` 四角色视觉识别。它不预测 Fe/V/Ti 含量、精矿品位、回收率或工业产线分选效果。

## 2. 核心网络创新

RSG-HRGV 不以“再增加一个普通注意力模块”为创新点，而是在固定的细粒度矿物种类--粗粒度选矿角色结构上引入可分析的专家路由机制：

1. **跨粒度双专家证据**：共享 EfficientNet-B0 主干产生特征 `h=f_theta(x)`；直接角色专家输出 `p_d`，17 类矿物种类专家输出 `p_s`，并由固定映射矩阵 `M` 得到种类映射角色后验 `p_m=M p_s`。两路后验处于同一四角色空间，但信息粒度不同。
2. **后悔监督门控**：训练期使用真实角色 `y` 计算两专家真值类对数损失 `l_d=-log p_d(y|x)` 与 `l_m=-log p_m(y|x)`，并由损失差给出连续软最优门控目标，而不是用硬阈值或事后人工规则训练门控。
3. **差距加权与局部梯度隔离**：专家差距越大，门控选错的理论代价越大；因此以有界权重强调此类样本。后悔分支对主干和专家证据使用 stop-gradient，使路由监督不反向重塑专家，从而把“改善专家”与“学习选择专家”区分开。
4. **验证器保留最终安全边界**：门控融合后验再经残差困难负样本验证器校正；训练期真值只参与损失，推理图没有标签输入。

## 3. 公式链与可证明性质

### 3.1 两路专家与凸融合

\[
\mathbf{u}_d=\mathbf{h}+A_d(\mathbf{h}),\quad
\mathbf{u}_s=\mathbf{h}+A_s(\mathbf{h}),\quad
\mathbf{p}_d=\operatorname{softmax}(W_d\mathbf{u}_d),\quad
\mathbf{p}_m=M\operatorname{softmax}(W_s\mathbf{u}_s).
\]

\[
p_g(y\mid x)=g(x)p_d(y\mid x)+[1-g(x)]p_m(y\mid x),\qquad 0\leq g(x)\leq1.
\]

这保证融合后验在两专家后验的凸包内；网络只重新分配已有证据，不能凭空制造超出两专家范围的单角色概率。

### 3.2 后悔目标

令 `Delta=l_m-l_d`，并令 `T_r>0`、`T_w>0`：

\[
g^*=\sigma\left(\frac{\Delta}{T_r}\right),\qquad
w=\tanh\left(\frac{|\Delta|}{T_w}\right),\qquad
\mathcal L_{reg}=w\,\operatorname{BCE}(g,g^*).
\]

若直接角色专家在真实类上概率更高，则 `Delta>0`，软目标更接近 1；反之更接近 0。两专家证据接近时，软目标保留连续不确定性且权重较小。

### 3.3 定理与经验对应

| 命题 | 结论 | 可检验指标 | 当前证据 |
| --- | --- | --- | --- |
| 定理 B.1 | 融合相对真值类概率更优专家的 NLL 后悔受 `|g-g_o||a-b|/epsilon` 上界控制 | 平均路由后悔 | 固定测试 RSG-HRGV 为 -1.77 pp，95% CI [-2.86, -0.69] |
| 定理 B.2 | 软目标与硬最优选择的偏差至多按 `exp(-|Delta|/T_r)` 衰减 | 软目标/硬目标消融；一对一错路由选择率 | 硬目标消融使路由后悔上升，见 `2026-08-25_rsg_theory_ablation.md` |
| 定理 B.3 | 在后悔分支使用 stop-gradient 时，该分支对共享主干和两专家的梯度为零 | 耦合门控消融；两类误入目标比例 | 受控消融保留局部梯度隔离；不将其表述为所有指标的普适优势 |
| 摄影者留出确认 | 固定摄影者与重复图像组不跨训练、验证、测试 | 平均路由后悔 | RSG-HRGV 为 -3.53 pp，95% CI [-4.75, -2.17] |
| ResNet50 主干替换确认 | B.1--B.3 只依赖融合层概率约束与 stop-gradient 计算图，而非特定 CNN 算子 | 平均路由后悔 | RSG-HRGV 为 -3.33 pp，95% CI [-4.86, -1.98]；其余分类指标区间跨零 |

其中 `g_o=I[p_d(y|x)\geq p_m(y|x)]`，`a=p_d(y|x)`，`b=p_m(y|x)`，且假设 `a,b` 位于 `[epsilon,1]`。上述定理约束的是当前计算图中的路由机制，不能推出 Accuracy、Macro F1 或工业分选指标必然提高。

## 4. 已验证的主张与禁止主张

### 可以作为论文核心主张

1. 提出并实现跨粒度双专家的 RSG-HRGV 网络，在固定种类--角色映射下显式分离直接角色证据与种类映射角色证据。
2. 给出真值类专家差距驱动的软后悔门控、差距加权和局部梯度隔离，并证明其路由后悔上界、软目标逼近及局部梯度范围。
3. 在固定测试集和摄影者留出确认集上，RSG-HRGV 均稳定降低预定义的平均路由后悔；两项证据均采用随机种子与 `split_group_id` 的两阶段 Bootstrap。
4. 在严格匹配的 ResNet50 三随机种子确认中，RSG 也稳定降低平均路由后悔，支持其融合层机制在第二种 CNN 主干上的经验可迁移性。
5. 建立可追溯数据审计、重复组隔离和来源留出协议，明确公开标本图像结论的适用边界。

### 必须限制的主张

1. RSG 的 Accuracy、Macro F1、目标类召回和两类误入目标比例的成对区间均未稳定优于 HRGV，不能称为总体分类性能显著提升。
2. M-RPG 的容量归一化、单调门控和凸融合是计算图性质；五随机种子扩展未支持其相对 RSG 的稳定经验优势。
3. 不能把 `target_recall` 称为回收率，把 `target intrusion` 称为工业杂质率。
4. ResNet50 确认并未给出稳定的 Accuracy、Macro F1、目标类召回或误入目标比例优势，不能将“主干替换不变性”写成任意主干上的性能保证或主干优劣结论。
5. 不写“实现工业分选”“钒钛品位检测”或“未知矿物识别”。

## 5. 论文结构建议（约 6,000--7,000 词）

1. **引言（900 词）**：公开标本图像的混合矿物、标签粒度不一致和来源偏差；提出跨粒度证据如何路由的问题。
2. **相关工作（1,100 词）**：矿物视觉分类、层级/细粒度学习、混合专家与选择性路由。重点说明本文不以“用了 CNN 或 Focal Loss”为创新。
3. **方法（1,550 词）**：任务和映射矩阵；双专家与残差验证器；RSG 损失；定理 B.1--B.3；训练和推理图分离。
4. **实验协议（850 词）**：数据审计、固定划分、摄影者留出、种子、指标、两阶段 Bootstrap 与预注册配置。
5. **结果（1,250 词）**：基线；RSG 对 HRGV 的路由后悔；软目标、权重和梯度隔离消融；摄影者留出；M-RPG 的五种子反证结果。
6. **讨论与结论（700 词）**：机制含义、为何路由改进不等价于总体分类增益、公共图像的限制、真实颗粒数据和阶段条件化决策作为后续工作。

## 7. 后续实验优先级

1. 用现有正式结果完成论文的“结果、讨论与结论”初稿，并在正文中明确所有跨零区间和 ResNet50 的受限含义。
2. 开展不依赖新增人工标签的门控可靠性补实验：按专家分歧、置信度和门控误差分层，验证 B.1 中的后悔上界是否能解释不同样本子群的路由难度；该实验只作为机制诊断，不替代分类性能指标。
3. 完成来源字段可用性审计后，增加按矿区或收藏机构留出的独立验证；若元数据不足，不虚构来源变量。
4. 采集或获得经专家确认的真实颗粒/标本外部测试集；只作外部评估，不与公开图片混合训练。
5. 只有当新增数据能支持阶段、误判代价或送检成本时，再进入阶段条件化选矿决策图研究；该方向不应由当前公开图片数据强行推导。
