# 面向钒钛矿相关矿物视觉角色识别的跨粒度后悔监督门控验证网络

> 论文初稿素材：方法与实验协议。本文档以 RSG-HRGV 为第一篇论文的主方法；M-RPG 仅作为理论约束扩展及其五随机种子反证性结果记录。

## 1. 任务定义与适用边界

给定公开矿物标本图像 \(x\)，本文研究固定闭集中的四角色视觉识别：目标矿物（`target_mineral`）、含钛干扰矿物（`ti_bearing_negative`）、脉石/废石（`gangue_negative`）和金属光泽困难负样本（`metallic_hard_negative`）。每张图像同时保留原始的 17 类矿物种类标签 \(s\) 作为辅助监督，并由预先固定的种类—角色映射矩阵 \(M\in\{0,1\}^{4\times17}\) 映射到角色标签 \(r\)。

本文的预测对象是公开标本图像的视觉角色，不是 Fe、V、Ti 元素含量，不预测精矿品位、实际回收率或生产线分选效果。文中“目标类召回”仅指固定测试协议下 `target_mineral` 的分类召回率；“误入目标比例”仅指非目标角色被分类器预测为目标角色的比例。

## 2. RSG-HRGV 网络

### 2.1 跨粒度双专家

主实验使用 ImageNet 预训练的 EfficientNet-B0 作为共享视觉主干，记其输出为

\[
\mathbf h=f_\theta(x).
\]

网络从共享特征导出两条语义粒度不同、但最终处于同一四角色概率空间的专家路径。直接角色专家输出

\[
\mathbf p_d=\operatorname{softmax}(W_d\mathbf u_d),
\]

其中 \(\mathbf u_d\) 为直接角色分支的残差适配特征；种类专家首先输出 17 类矿物种类后验

\[
\mathbf p_s=\operatorname{softmax}(W_s\mathbf u_s),
\]

再由固定映射聚合为角色后验

\[
\mathbf p_m=M\mathbf p_s.
\]

两路专家分别回答“图像直接支持哪个角色”和“图像更像哪种矿物、该矿物对应哪个角色”。它们的分歧并不必然代表错误：公开标本图像可能同时出现伴生矿物、基质、人工背景或多个形态特征，因而细粒度种类线索与粗粒度角色线索可能不一致。

### 2.2 后悔监督门控融合

可靠性门控 \(g(x)\in[0,1]\) 对两路证据执行凸融合：

\[
\mathbf p_f=g(x)\mathbf p_d+[1-g(x)]\mathbf p_m.
\]

该形式保证每个角色的融合概率位于两位专家对应概率之间，网络只重分配既有证据，而不会在两位专家之外凭空构造概率。训练时，对真实角色 \(y\) 定义两位专家的真值类对数损失

\[
\ell_d=-\log p_d(y\mid x),\qquad
\ell_m=-\log p_m(y\mid x),\qquad
\Delta=\ell_m-\ell_d.
\]

若直接角色专家对真实类的证据更强，则 \(\Delta>0\)。以此构造连续的软最优门控目标与差距权重：

\[
g^*=\sigma\left(\frac{\Delta}{T_r}\right),\qquad
w=\tanh\left(\frac{|\Delta|}{T_w}\right),\qquad
\mathcal L_{reg}=w\,\operatorname{BCE}(g,g^*).
\]

其中 \(T_r>0\) 控制软目标温度，\(T_w>0\) 控制专家差距的强调程度。当两位专家对真实类证据接近时，\(g^*\) 保留不确定性且 \(w\) 较小；当差距增大时，门控选择错误造成的潜在后悔更大，训练会更加重视该样本。

为将“改善专家本身”与“学习在两位专家之间路由”区分开，\(\mathcal L_{reg}\) 分支对主干和专家证据使用 stop-gradient。主任务、种类任务和验证器任务仍以各自损失更新网络；后悔监督在该分支中只更新门控参数。

### 2.3 困难负样本残差验证器

在融合后验 \(\mathbf p_f\) 的基础上，网络设置目标矿物—含钛干扰和目标矿物—金属光泽干扰两个残差验证器。验证器在对立证据达到设定阈值时衰减目标角色后验，在支持性或中性区间保持恒等，从而避免简单相乘式校正对支持性证据产生反向惩罚。最终输出记为 \(\mathbf q\)。

总训练目标由角色分类、种类分类、直接角色分类、KL 一致性、两个验证器、角色感知对比学习和门控后悔损失组成：

\[
\mathcal L=\mathcal L_{role}+\lambda_d\mathcal L_{direct}+\lambda_s\mathcal L_{species}
+\lambda_c\mathcal L_{KL}+\lambda_v(\mathcal L_{Ti}+\mathcal L_{Met})
+\lambda_{con}\mathcal L_{contrast}+\lambda_g\mathcal L_{reg}.
\]

训练期的真实标签仅用于计算损失；推理图仅接收图像并输出 \(\mathbf q\)，不存在将真实标签输入推理阶段的路径。

## 3. 可证明性质及其可检验含义

记 \(a=p_d(y\mid x)\)、\(b=p_m(y\mid x)\)，并假设 \(a,b\in[\epsilon,1]\)，\(\epsilon>0\)。令硬最优选择为 \(g_o=\mathbb I[a\geq b]\)。对融合后验，有

\[
-\log p_f(y\mid x)+\log\max(a,b)
\leq \frac{|g-g_o|\,|a-b|}{\epsilon}.
\]

该不等式表明，门控偏离真实类概率更优专家所带来的负对数似然后悔，受门控误差和两专家证据差距共同控制。它对应的经验指标是预先定义的平均路由后悔，而不是 Accuracy 或 Macro F1。

其次，软目标 \(g^*\) 对硬最优选择的偏差随证据差距指数衰减：

\[
|g^*-g_o|\leq \exp\left(-\frac{|\Delta|}{T_r}\right).
\]

这解释了为何在专家差距很小的样本上不采用硬切换。最后，在后悔分支使用 stop-gradient 时，该分支对主干及两位专家参数 \(\theta_e\) 的局部梯度为

\[
\frac{\partial\mathcal L_{reg}}{\partial\theta_e}=0.
\]

进一步地，记任意视觉主干为 \(f_{\theta}^{(b)}\)，只要其经两条预测头输出满足单纯形约束的 \(\mathbf p_d^{(b)}\) 与 \(\mathbf p_m^{(b)}\)，并使用同一凸融合 \(\mathbf p_f^{(b)}=g^{(b)}\mathbf p_d^{(b)}+[1-g^{(b)}]\mathbf p_m^{(b)}\)，则上述三条性质对任意 \(b\) 均成立。原因是 B.1--B.2 的推导只涉及真实角色上的标量概率、\(g\in[0,1]\) 及对数函数的局部 Lipschitz 界，B.3 只涉及后悔分支的计算图截断，而不涉及 \(f_{\theta}^{(b)}\) 的卷积或注意力算子。本文将此称为**主干替换不变性命题**：RSG 的后悔上界、软目标逼近界和局部梯度隔离是融合层性质，而非 EfficientNet-B0 的专有性质。该命题不推出任意主干都有更低的经验后悔或更高的分类性能，故使用严格匹配的 ResNet50 三随机种子实验进行经验检验。

上述三条性质是当前公式和计算图的局部、确定性结论。它们不推出总体分类性能必然提高，故需与预注册多随机种子实验、成对置信区间和消融实验逐一对应。

为避免常规逐图 CSV 的六位小数导出将极小概率舍入为零，进一步使用保存的最佳检查点对固定测试三种子和摄影者留出三种子进行只读重放，以 15 位小数重新导出门控及两路真值概率。6 次重放共覆盖 6,390 张图像；在 float32 概率下界 \(1.19\times10^{-7}\) 和数值容差 \(2\times10^{-6}\) 下，定理 B.1 的最大残差为 \(-5.96\times10^{-8}\)、定理 B.2 的最大残差为 \(5.94\times10^{-8}\)，两者违反计数均为 0。该结果是对已实现计算图的高精度数值一致性验证，不是新的分类性能、工业分选、品位、回收率、外部泛化或 OOD 结论。

## 4. 数据、划分与训练协议

数据来源为公开 Mindat 标本图片。数据流程保留下载清单、种类—角色映射、SHA-256 完全重复、Mindat 图片编号和 dHash 近重复控制记录；同一 `split_group_id` 不跨训练、验证和测试划分。正式固定四角色数据集中共有 8,529 张图像，其中训练集 5,961 张、验证集 1,284 张、测试集 1,284 张。

所有主实验 RSG-HRGV 与 HRGV 参考模型使用相同的 ImageNet 预训练 EfficientNet-B0 主干、图像增强、优化器、早停策略、固定数据划分和残差验证器耦合方式。正式比较使用随机种子 20260727、20260728 和 20260729。统计比较以图片 `split_group_id` 为聚类单位，并在随机种子和完整图片组两个层面进行成对 Bootstrap 重采样；固定测试采用 2,000 次重采样。为验证“主干替换不变性命题”的经验边界，另以同一协议在 ImageNet 预训练 ResNet50 上重复 HRGV 参考与 RSG 对照；该确认不用于主干优劣比较。

为检验来源风格变化下的机制稳定性，另使用摄影者或图片署名字段实施来源留出确认。该协议纳入具有摄影者字段的 5,639 张图像，训练/验证/测试分别为 3,947/846/846，且摄影者与重复图像组均不跨集合。三次确认种子为 20260727、20260729 和 20260730；筛选性试运行种子 20260728 不计入正式估计。摄影者留出仍来自公开标本图片，因此只能称为来源留出确认，不能称为工业外部测试或 OOD 验证。

## 5. 指标与结果陈述规则

报告 Accuracy、Macro F1、目标类召回、目标类漏判率、含钛干扰误入目标比例、金属光泽干扰误入目标比例、Brier score、ECE、单边正确样本的门控选择率和平均路由后悔。Brier score 与 ECE 用于后验质量评价；两类误入目标比例和目标类召回均是分类代理指标，不可替代品位、回收率或工业杂质率。

在固定测试上，RSG-HRGV 相对严格匹配的 HRGV 参考模型的平均路由后悔变化为 -1.77 个百分点，95% Bootstrap 区间为 [-2.86, -0.69] 个百分点；摄影者留出确认中对应差值为 -3.53 个百分点，区间为 [-4.75, -2.17] 个百分点。两个区间均低于零，支持 RSG 机制在已定义指标上的稳定后悔下降。

与此同时，固定测试和摄影者留出中的 Accuracy、Macro F1、目标类召回以及两类误入目标比例的成对区间均有跨零项。因此本文只能主张 RSG-HRGV 降低了预定义的平均路由后悔，不主张其总体分类性能优于 HRGV，更不主张工业分选效果提升。

### 5.1 主干替换确认：ResNet50

为检验第 3 节的主干替换不变性命题是否仅是 EfficientNet-B0 实现的偶然现象，在不改变数据划分、四角色/17 类种类标签、损失项、门控温度、残差验证器、训练轮次上限和三随机种子的条件下，将共享视觉主干替换为 ImageNet 预训练 ResNet50，并重复 HRGV 参考与 RSG-HRGV 的成对实验。该实验检验的是融合层机制在另一类卷积主干上的经验可迁移性，不构成 ResNet50 与 EfficientNet-B0 的主干性能比较。

| 指标 | ResNet50 HRGV（均值） | ResNet50 RSG-HRGV（均值） | RSG - HRGV 成对差值，95% Bootstrap 区间 |
|---|---:|---:|---:|
| Accuracy | 75.36% | 76.64% | +1.27 pp [-0.44, +3.12] |
| Macro F1 | 73.29% | 74.28% | +0.99 pp [-0.75, +2.88] |
| 目标类召回 | -- | -- | -0.13 pp [-6.24, +6.78] |
| 含钛干扰误入目标比例 | -- | -- | -0.75 pp [-4.01, +2.58] |
| 金属光泽干扰误入目标比例 | -- | -- | +2.27 pp [-1.89, +6.63] |
| 平均路由后悔 | 11.84% | 8.51% | **-3.33 pp [-4.86, -1.98]** |

三个 ResNet50 随机种子的平均路由后悔差值分别为 -2.77、-4.63 和 -2.59 个百分点，均为下降；聚类 Bootstrap 区间也完全低于零。与之相对，Accuracy、Macro F1、目标类召回和两类误入目标比例的区间均跨零。故该确认支持如下受限结论：在本数据、协议和两位专家定义不变时，RSG 的后悔监督在 ResNet50 上也能稳定改善预定义路由指标；它不证明 RSG 必然提高任意主干的分类性能，也不证明 ResNet50 优于 EfficientNet-B0。

## 6. M-RPG 理论扩展的报告方式

M-RPG 将 17 类种类后验的不确定性按固定角色映射分解为角色间与角色内两部分，并对门控输入实施容量归一化和角色间不确定性单调约束。其熵分解、归一化范围、单调导数与凸融合包络是可验证的公式性质。

但在五随机种子扩展中，M-RPG 相对 RSG 的 Macro F1、目标类召回、两类误入目标比例、Brier score 和 ECE 的成对区间均跨零。因此，本文将 M-RPG 作为理论驱动扩展和可复核的负结果记录，而不将其作为第一篇论文的主要性能创新。后续只有在来源留出或独立真实图像中观察到稳定效果，才考虑将其发展为独立方法论文。
