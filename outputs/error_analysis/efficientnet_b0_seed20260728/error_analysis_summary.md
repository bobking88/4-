# EfficientNet-B0 测试集错分分析（随机种子 20260728）

## 分析对象

- 模型：EfficientNet-B0
- 数据版本：`dataset_final_v1`
- 测试集：1,284 张固定测试图像
- 正确预测：968 张
- 错分样本：316 张，占测试集 24.61%
- 本目录中的 `test_predictions.csv` 记录了每张测试图像的真实类别、预测类别、置信度和来源标识；`misclassified_samples.csv` 仅保留错分样本。

## 主要混淆方向

| 真实类别 -> 预测类别 | 错分数量 | 占测试集比例 |
|---|---:|---:|
| 含钛干扰矿物 -> 脉石/废石 | 50 | 3.89% |
| 含钛干扰矿物 -> 目标矿物 | 43 | 3.35% |
| 脉石/废石 -> 含钛干扰矿物 | 40 | 3.12% |
| 目标矿物 -> 含钛干扰矿物 | 40 | 3.12% |
| 脉石/废石 -> 金属光泽干扰 | 23 | 1.79% |
| 含钛干扰矿物 -> 金属光泽干扰 | 23 | 1.79% |

完整统计见 `error_pair_summary.csv`；`error_contact_sheets/` 中按“真实类别__as__预测类别”保存了每种错误对中置信度最高的代表性样本，便于人工复核。

## 解释

1. **含钛干扰矿物是当前主要难点。** Perovskite、Titanite、Rutile、Anatase 等含钛矿物与目标矿物在暗色块状、晶面反光和伴生基质等视觉特征上存在重叠，因此既会被误判为目标矿物，也会被误判为脉石/废石。
2. **目标矿物与含钛干扰矿物存在双向混淆。** 40 张目标矿物被识别为含钛干扰矿物，说明仅依赖公开标本照片的颜色和形貌，仍不足以稳定表达矿物的工业可回收属性。
3. **金属光泽干扰仍需针对性加强。** 虽然该模型对金属光泽干扰矿物的召回率较 ResNet50 更高，但其样本仍可能被识别为目标矿物、含钛干扰或脉石，反映出反光、暗背景和块状形态是重要干扰因素。

## 可写入论文或结题报告的表述

为分析模型失效模式，本文对 EfficientNet-B0 在固定测试集上的逐图预测结果进行了追溯。1,284 张测试图像中共有 316 张被错分，错误主要集中于含钛干扰矿物与脉石/废石、目标矿物之间的混淆。其中，含钛干扰矿物被误判为脉石/废石和目标矿物的数量分别为 50 张和 43 张。这表明公开矿物标本图像中不同矿物类别在颜色、金属光泽、晶体形貌和共生基质方面存在明显视觉重叠。后续工作可围绕含钛干扰矿物补充更具代表性的样本，并引入真实矿石颗粒或传送带图像开展领域适配，以提升面向工业分选场景的泛化能力。

## 后续改进实验建议

1. 对含钛干扰矿物进行定向增样，并保持各来源矿物的类别内部多样性。
2. 以 `target_mineral` 与 `ti_bearing_negative` 为重点，比较类别重加权、难例重采样和更强颜色/光照增强的效果。
3. 获取少量真实钒钛矿颗粒或皮带图像，作为独立外部测试集，避免将公开标本图像性能直接等同于工业分选性能。
